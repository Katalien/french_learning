# Data Model: Правки после первого использования

Схема базы прогресса и формат контента **не меняются**.

## Карточка (`cards`)

- Ключ `(entry_id, direction)`, `direction ∈ {fr_ru, ru_fr}`.
- Новое правило: у каждого нескрытого слова — обе карточки. `CardStore.sync` создаёт только
  недостающие (R1, R2). Карточки ru_fr для уже добавленных слов появляются при первом `sync`
  новой версии как новые (срок — момент создания). Существующие карточки и `reviews`
  не меняются.

## Настройки (`settings`)

| Ключ | Было | Стало |
|---|---|---|
| `directions` | `staged` / `both`, в «Настройках» | не читается и не показывается (строка в базе остаётся) |
| `portion_size` | в «Настройках», только для сеансов из словаря | на странице настройки повторения; последнее введённое число; пусто в форме = все |

## Параметры сеанса (`sessions.params`, JSON)

- `SessionParams` получает поле `portion: int | None` (None — все). Старые сеансы без поля
  читаются со значением по умолчанию.
- `queue` — перемешанная при создании (R3); после создания не меняется.
- `source` остаётся для совместимости, но размер подхода определяется `portion`.

## Сообщение об ошибке (`reports/*.yaml` в хранилище)

- Формат не меняется. Для отметки «сообщение отправлено» читаются открытые сообщения
  с `element == id упражнения` и `item == номер пункта`.

## Выполнение упражнения

- `exercise_done(e) = e.part == "class" or есть полная проверка / сохранённый ответ`.
  Попытки (`attempts`) не меняются; классная работа не требует записи в базе.
