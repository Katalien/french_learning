# Quickstart: проверка 010

## Подготовка

```bash
uv run pytest
uv run ruff check .
uv run french-learning demo-init <папка-демо>
uv run french-learning serve --port 8010 --content-dir <папка-демо>
```

Проверять только на демо (порт 8010) — настоящий прогресс не трогать.

## Сценарии

1. **Скорость (пункт 8, SC-007).** Повторение «Все слова» → «Помню» несколько раз: следующая
   карточка появляется практически сразу. Замер на копии настоящего хранилища (скрипт замера
   из research R1): запрос `/practice/{id}` < 0,25 с.
2. **Обе стороны (решение 2026-10-02).** «Настройки» — нет блоков «Новые слова» и «Карточек за
   один подход». Настройка повторения: «Все слова», «русский → французский» — счётчик равен
   числу нескрытых слов без «Знаю».
3. **Из урока (пункты 3, 6).** Урок → «Лексика» → «Повторить слова урока» → открыта настройка,
   выбран «По уроку» и этот урок, «Слов за подход» пусто (все). Выбрать «русский →
   французский» — счётчик = все слова урока. «Начать» → столько карточек.
4. **Перемешивание (пункт 5).** Дважды запустить один и тот же сеанс — первые карточки разные.
5. **Род (пункт 2).** Сеанс ru→fr со словом женского рода: лицевая сторона нейтральная, без
   метки; после переворота — цвет и метка рода. Режим ввода — то же до проверки.
6. **Тема с поиском (пункт 11).** «По теме» → клик в поле — весь список; ввести «ali» —
   остаются темы со словом «aliments» / «Алименты»… (без регистра и акцентов); стрелки + Enter
   выбирают; Escape закрывает; «zzz» → «Ничего не найдено».
7. **Соседи слова (пункт 1).** Словарь → фильтр по уроку → второе слово → «›» — третье, «‹» —
   первое; у первого нет «‹»; «N из M» совпадает со списком.
8. **Панель букв (пункт 4).** Длинное упражнение с вводом → панели наверху нет; курсор в поле
   пункта 5 — панель под этим пунктом, «é» вставляется в поле; клик вне полей — панель скрыта.
9. **Рядом (пункт 9).** Упражнение с теорией (и с текстом) на широком окне: ссылок «… к
   упражнению» нет, рядом открыт текст (или теория), есть «Открыть отдельной страницей»;
   на 375 px само ничего не открывается.
10. **Картинка (пункт 10).** Обычное упражнение из фото — «Показать картинку», по умолчанию
    свёрнута; упражнение «по картинке» — открыта сразу.
11. **Сообщение (пункт 7, SC-004).** Проверить упражнение с ошибкой → «Не согласна с ответом» →
    текст → «Отправить сообщение»: кнопка сразу «Отправляю…», затем у пункта «Сообщение
    сохранено…» и метка «✉ сообщение отправлено»; ответы в полях на месте; пустой текст —
    подсказка, в хранилище ничего.
12. **Классная работа (пункт 12).** Урок → «В классе» — у всех упражнений «✓ выполнено».
13. **Телефон.** 375 px: настройка повторения, поле темы, страница слова со стрелками.
