## Summary

Двенадцать правок по итогам первого использования, без нового формата контента и без новых
зависимостей. Они сгруппированы по местам в коде:

- **Повторение слов** (`vocab/cards.py`, `vocab/sessions.py`, `web/routes/vocab.py`,
  `vocab/practice_setup.html`):
  - карточки заводятся только недостающие (пункт 8: ≈ 1,8 с → доли секунды);
  - у каждого слова сразу обе карточки, настройка «поэтапно» убирается (решение 2026-10-02);
  - очередь перемешивается (пункт 5);
  - «слов за подход» — на странице настройки, по умолчанию «все» для урока и темы (пункт 6);
  - «Повторить слова урока» → страница настройки с выбранным уроком (пункт 3);
  - выбор темы — поле с поиском по мере ввода (пункт 11);
  - счётчик «в сеансе N карточек» обновляется при смене настроек.
- **Карточка** (`vocab/practice_card.html`, CSS): «русский → французский» — лицевая сторона
  без цвета и метки рода (пункт 2).
- **Словарь** (`vocab_entry`, `vocab/entry.html`, `vocab/list.html`): стрелки «‹ ›» и «N из M»
  по списку с теми же фильтрами (пункт 1).
- **Упражнение** (`element.html`, `exercises/solve.html`, `symbols.js`, CSS):
  - панель букв под полем с курсором (пункт 4);
  - без ссылок «… к упражнению», «рядом» открыто сразу на широком экране, ссылка «Открыть
    отдельной страницей» (пункт 9);
  - картинка исходного листа у всех упражнений с картинкой, необязательная — свёрнута (пункт 10);
  - сообщение «Не согласна с ответом»: «Отправляю…» сразу, подтверждение у пункта, пометка
    «сообщение отправлено», без лишнего перечитывания контента (пункт 7).
- **Классная работа** (`content/index.py`, `web/routes/lessons.py`): упражнения части
  «В классе» всегда выполнены (пункт 12).

## Technical Context

**Language/Version**: Python 3.12 (uv)

**Primary Dependencies**: без новых — FastAPI, Jinja, HTMX, Alpine.js, `fsrs`, `random`

**Storage**: база прогресса — схема не меняется. Настройка `directions` больше не читается
(строка в `settings` остаётся, ни на что не влияет). `portion_size` остаётся и теперь
пишется со страницы настройки повторения. Сообщения об ошибках — как раньше,
`reports/*.yaml` в хранилище.

**Testing**: pytest, TDD (принцип XIII):
- `CardStore.sync` — заводит только недостающие карточки и обе стороны; повторный вызов
  не создаёт объектов FSRS (подмена `fsrs.Card` счётчиком);
- очередь — перемешивание с подменяемым генератором, порядок «сегодня» (сначала
  повторявшиеся, затем новые);
- размер подхода из формы, «все», запоминание;
- маршруты: `/lessons/{n}/practice` → настройка, `/practice/count`, `/vocab/{id}` с соседями,
  классная работа выполнена, отчёт — подтверждение у пункта, пустой комментарий;
- разметка: карточка ru_fr без рода на лицевой стороне, нет ссылок «… к упражнению»,
  кнопка картинки, одна панель букв.

Поведение в браузере (панель букв под полем, открытие «рядом», фильтр тем) — по quickstart.

**Target Platform**: браузер компьютера; телефон — вёрстка 375 px

**Project Type**: веб-приложение (сервер FastAPI + шаблоны)

**Performance Goals**: оценка карточки + следующая карточка < 0,5 с на 500 словах (SC-007);
отправка сообщения — «Отправляю…» сразу, без ожидания на пустой странице

**Constraints**: прогресс направления «французский → русский» не меняется; история оценок
сохраняется (VII); всё локально (IX)

**Scale/Scope**: ~8 модулей и ~10 шаблонов правятся, 1 новый частичный шаблон (поле
с поиском), 1 новый адрес (`/practice/count`), ~35 тестов
