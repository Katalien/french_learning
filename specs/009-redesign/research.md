# Research: Редизайн интерфейса

Решения по технически неясным местам. Формат: решение → почему → что ещё рассматривали.
Выбор оформления — [design.md](design.md).

## R1. Своя система оформления вместо Pico CSS

- **Решение**: убрать Pico CSS и написать свою небольшую систему оформления: `static/css/`
  с токенами (цвета светлой и тёмной темы, шрифты, радиусы, тени), базовыми стилями,
  компонентами (кнопки, чипы, блоки, вкладки, круги прогресса, поля, таблицы) и стилями
  экранов. Файлы: `tokens.css`, `base.css`, `components.css`, `screens.css` (подключаются
  по порядку, без сборки).
- **Почему**: выбранный дизайн сильно отличается от Pico. Pico навязывает ширину кнопок,
  отступы и оформление форм, и это пришлось бы постоянно перебивать (так было в 003–004).
  Своя система на CSS-переменных короче и предсказуемее. Конституция Pico не фиксирует,
  стек (HTMX, Alpine, без сборки) не меняется.
- **Альтернативы**: оставить Pico с темой — много переопределений; Tailwind — нужна сборка,
  против конституции (стек без сборки фронтенда).

## R2. Шрифты локально

- **Решение**: Inter и Lora (лицензия SIL OFL) в формате woff2, с кириллицей и латиницей,
  в `static/fonts/` вместе с файлами лицензий; `@font-face` в `tokens.css`. Скачать один раз,
  по согласию пользователя, из официальных репозиториев шрифтов.
- **Почему**: приложение работает без интернета (принцип IX); Google Fonts в макете — только
  для обсуждения.
- **Альтернативы**: системные шрифты — не совпадут с выбранным видом.

## R3. Тема оформления без мигания

- **Решение**: выбор (светлая / тёмная / как в системе) хранится в cookie `theme` браузера;
  сервер ставит `data-theme` на `<html>` при отрисовке. Для «как в системе» тёмные токены
  включаются через `@media (prefers-color-scheme: dark)`. Переключатель — в меню «⋯»
  и в «Настройках» (форма без JavaScript + мгновенное применение через Alpine).
- **Почему**: без мигания светлой темы при загрузке (выбор известен серверу); как переключатель
  происхождения в 001 (`show_origin`).
- **Альтернативы**: `localStorage` — мигание при загрузке; настройка в базе прогресса —
  это предпочтение устройства, а не данные обучения.

## R4. Главная «Сегодня» и адреса

- **Решение**: `/` — экран «Сегодня»; список уроков переезжает на `/lessons`. Данные
  «Сегодня» — из существующих модулей: карточки «пора» (`CardStore.due`), невыполненная
  основная домашка двух последних уроков с домашкой (`ExerciseProgress`), встроенные
  тренажёры с вопросами «пора» (`TrainerSchedule.due_count`).
- **Почему**: FR-003; «Уроки» в шапке ведут на отдельную страницу.
- **Производительность**: подсчёт «пора» по всем встроенным тренажёрам генерирует вопросы
  (числа — 1001); кешировать список ключей по отпечатку контента, чтобы «Сегодня»
  открывалось < 300 мс.

## R5. Разделы урока

- **Решение**: `/lessons/{n}` — «Обзор»; `/theory`, `/texts`, `/vocab` (новый), `/tasks`;
  медиаматериалы — внизу `/tasks`. Общий шаблон урока с боковой панелью разделов.
  Панель закрывается кнопкой (Alpine, состояние только на странице — при каждом входе
  открыта, как решил пользователь); на узком экране — сворачивается в кнопку
  «☰ Разделы урока».
- **Почему**: FR-010–FR-013, design.md.

## R6. Настройки и происхождение за кнопками

- **Решение**: «⚙» (урок, упражнение) и «ⓘ» (упражнение, теория, текст) — раскрывающиеся
  панели на Alpine (`x-show`), формы внутри — обычные формы с перезагрузкой страницы, как
  в 001–004. Метки происхождения в списках показываются только при включённом глобальном
  переключателе (`show_origin`).
- **Почему**: FR-013, FR-022, FR-023; без новой серверной логики.

## R7. Соседние упражнения и меню урока

- **Решение**: `ContentIndex.neighbours(exercise)` — предыдущее и следующее упражнение той же
  вкладки урока (без резерва), для «Доп. материалов» — среди упражнений раздела. Меню урока
  на странице упражнения («☰ Урок N») — выезжающая панель с деревом урока и отметками
  выполненного (`ExerciseProgress`). Стрелки ‹ › — ссылки по краям страницы (на узком
  экране — внизу, над кнопками).
- **Почему**: FR-024, FR-025, SC-002.

## R8. Теория рядом с упражнением

- **Решение**: кнопка «Теория рядом» / «Текст рядом» загружает фрагмент элемента
  (`GET /elements/{id}?fragment=1`) через HTMX во вторую колонку; экран делится пополам
  (CSS grid 1fr 1fr), кнопка «✕» закрывает. На экране уже 900 px фрагмент открывается
  поверх упражнения (фиксированная панель). Черновик и проверка упражнения не затрагиваются —
  это другой блок страницы.
- **Почему**: FR-032, SC-003; без изменения логики упражнений.

## R9. Навигация по нескольким теориям и текстам

- **Решение**: раздел «Теория» (и «Тексты») — двухколоночная раскладка: слева закреплённое
  оглавление всех элементов раздела и их подзаголовков (из существующего `headings()`), справа
  элементы подряд с якорями. На узком экране оглавление — сворачиваемый блок над текстом.
- **Почему**: FR-030; сейчас оглавление есть только внутри одной теории и только от трёх
  заголовков.

## R10. Страница темы по вкладкам и повторение слов темы

- **Решение**: `/topics/{id}?tab=theory|texts|exercises|words` — вкладки со счётчиками,
  пустые скрыты, по умолчанию первая непустая. Во вкладке «Слова» — кнопка «Повторить слова
  темы»: POST на существующий `/practice/start` с `mode=topic`.
- **Почему**: FR-040.

## R11. «Практика» и повторение

- **Решение**: `/practice` — страница-хаб: «Повторение слов» (счётчик «пора», «Повторить» —
  сеанс «пора сегодня», «Настроить» → `/practice/setup`, прежняя страница настройки),
  «Мои ошибки», «Тренажёры» (карточки каталога). Кнопка повторения со страницы «Словарь»
  убирается. Старые адреса (`/trainers`, `/mistakes`) продолжают работать.
- **Почему**: FR-041, FR-042; уточнение сессии 2026-09-28.

## R12. Вид списка заданий

- **Решение**: настройка `exercise_list_view` (`rows` / `tiles`, по умолчанию `rows`)
  в базе прогресса (как размер порции), меняется в «Настройках». Один шаблон списка
  с двумя вариантами разметки.
- **Почему**: FR-020a; решение пользователя «только в настройках».

## R13. Проверка результата

- **Решение**: существующие интеграционные тесты, проверяющие HTML, обновляются под новую
  разметку (поведение не меняется — SC-007); новые тесты: «Сегодня», раздел «Лексика»,
  соседние упражнения, фрагмент для разделения экрана, вкладки темы, хаб «Практика», cookie
  темы, настройка вида списка, отсутствие дублей навигации (SC-001). Вид — вручную по
  quickstart на ширине компьютера и 375 px, в светлой и тёмной теме.
