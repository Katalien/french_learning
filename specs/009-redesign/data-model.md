# Data Model: Редизайн интерфейса

Контент и база прогресса не меняются по структуре. Новое — только предпочтения интерфейса.

| Что | Где | Значения | По умолчанию |
|---|---|---|---|
| Тема оформления | cookie браузера `theme` | `light` / `dark` / `system` | `system` |
| Вид списка заданий | `settings.exercise_list_view` в базе прогресса | `rows` / `tiles` | `rows` |
| Показ происхождения | cookie `show_origin` (001, без изменений) | `0` / `1` | `0` |
| Панель разделов урока | состояние страницы (не хранится) | открыта / закрыта | открыта при каждом входе |
| Разделение экрана | состояние страницы (не хранится) | вкл / выкл | выкл |

Вычисляемые данные экранов (без хранения):

- **«Сегодня»**: число карточек «пора» (+ новых), до двух последних уроков с домашкой и их
  невыполненные основные упражнения, встроенные тренажёры с `due_count > 0`.
- **Соседи упражнения**: предыдущее / следующее в той же вкладке урока без резерва.
- **Дерево урока**: теории, тексты, лексика, упражнения по вкладкам с отметкой выполнения.
- **Вкладки темы**: элементы темы по видам со счётчиками.
