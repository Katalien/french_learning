# Дизайн 009: принятые решения

Выбор пользователя по макетам (2026-09-28). Итоговый макет — [mockups/final.html](mockups/final.html);
варианты для сравнения — [mockups/index.html](mockups/index.html) (v1), [mockups/v2.html](mockups/v2.html).

## Стиль

| Что | Решение |
|---|---|
| Настроение | лёгкое, живое, не яркое; баланс красоты (цвет, геометрия) и функциональности |
| Палитра | «Перелив»: #FADCFE · #C7F3F6 · #FEFDF9 · #A4C6E9 · #838BCC · #B8AEE3; фон бумажный #FDFCF8 |
| Перелив фона | заметный (радиальные розово-бирюзово-лавандовые пятна) |
| Тёмная тема | тёмно-синяя (#1C1E33), не чёрная; переключатель светлая / тёмная / как в системе |
| Шрифты | интерфейс — Inter; теория и тексты — Lora (книжный) |
| Французские слова | цветом, лавандовый (#6D62BD, в тёмной — #C5BCF7); примеры — курсивом |
| Род | m — голубой, f — розовый |
| «В классе» / «Домашка» | цвета из палитры (аква / лаванда) |
| Скругление | слегка (8–10 px) |
| Блоки | с тенью, полупрозрачная подложка |
| Кнопки | главная — с переливом (градиент), остальные — контурные или текстовые; одного размера в группе |
| Иконки | нет, только служебные знаки ⚙ ⓘ ☰ ‹ › |
| Прогресс | кругами |
| Анимации | немного: появление экранов, переворот карточки, раскрытие панелей |
| Реакция на ответ | спокойная: цвет и значок, без анимации и звука |
| Мотивация | нет |

## Раскладка

| Что | Решение |
|---|---|
| Главное меню | сверху: Уроки · Словарь · Практика · Темы · «⋯» |
| Навигация по уроку | боковая панель «только разделы» (Обзор, Теория, Тексты, Лексика, Задания), закрывается; при каждом открытии урока — снова открыта |
| Теория / тексты | внутри раздела — закреплённое оглавление по всем темам раздела и их подзаголовкам |
| Меню урока на странице упражнения | выезжает по «☰ Урок N» (как в макете v1) |
| Список заданий | по умолчанию список; плитки — переключатель **только в «Настройках»** |
| Словарь | строки: цветная полоса рода, слово, перевод, урок, озвучка |
| Карточка повторения | «чистая», по центру, как настоящая карточка; полоса рода сверху шире (14 px); переворот |
| Горячие клавиши | подумать позже |
