**Branch**: `009-redesign` | **Date**: 2026-09-28 | **Spec**: [spec.md](spec.md)

## Summary

Переделка интерфейса без изменения логики. Pico CSS заменяется своей системой оформления:
палитра «Перелив», Inter + Lora, светлая и тёмная тема, шрифты хранятся локально.
Навигация становится короче: четыре раздела и «⋯», главная — экран «Сегодня».

Что меняется на экранах:
- **Урок** — боковая панель разделов, отдельная «Лексика», медиа внизу «Заданий»,
  настройки за «⚙».
- **Упражнение** — путь вверху, темы один раз, «⚙» и «ⓘ», стрелки ‹ ›, меню урока,
  «Теория рядом».
- **Теория и тексты** — оглавление по всем элементам раздела, выделенные таблицы.
- **Темы** — вкладки по видам материалов.
- **Практика** — одна страница-хаб: повторение, ошибки, тренажёры.
- **Карточки, словарь, тренажёры** — новый вид.

Сервер меняется немного: новые адреса (`/lessons`, `/lessons/{n}/vocab`,
`/practice/setup`, фрагмент элемента, тема оформления), соседние упражнения, данные для
«Сегодня», вкладки темы, настройка вида списка. Остальное — шаблоны и стили.

## Technical Context

**Language/Version**: Python 3.12 (uv)

**Primary Dependencies**: без изменений в Python. В интерфейсе убирается Pico CSS
и добавляются шрифты Inter и Lora (woff2, SIL OFL), локально в `static/fonts/`

**Storage**: без изменений структуры. Новые предпочтения: cookie `theme`, настройка
`exercise_list_view` в базе прогресса (data-model.md)

**Testing**: pytest. Интеграционные тесты страниц обновляются под новую разметку. Новые
тесты: «Сегодня», «Лексика», соседи, фрагмент, вкладки темы, хаб, тема оформления, вид
списка, отсутствие дублей навигации. Вид проверяется вручную по quickstart на компьютере
и 375 px, в светлой и тёмной теме

**Target Platform**: браузер компьютера (основной), телефон (вёрстка на 375 px)

**Project Type**: переделка интерфейса веб-приложения

**Performance Goals**: «Сегодня» < 300 мс (ключи вопросов тренажёров кешируются по отпечатку
контента); остальные страницы — как сейчас

**Constraints**: без интернета (шрифты и стили локально); без сборки фронтенда; поведение
001–004 не меняется (SC-007)

**Scale/Scope**: ~55 шаблонов, 1 файл стилей → 4 файла, ~8 новых или изменённых маршрутов

```text
src/french_learning/web/
├── static/
│   ├── css/tokens.css          # палитра, тёмная тема, шрифты (@font-face), радиусы, тени
│   ├── css/base.css            # сброс, типографика, ссылки, формы, таблицы
│   ├── css/components.css      # кнопки, чипы, блоки, вкладки, круги, панели, поповеры
│   ├── css/screens.css         # экраны: сегодня, урок, упражнение, карточка, словарь…
│   ├── fonts/                  # Inter, Lora (woff2) + OFL.txt
│   └── vendor/                 # htmx, alpine (pico удаляется)
├── templates/
│   ├── base.html               # новая шапка, «⋯», data-theme
│   ├── today.html · lessons.html · practice.html   # новые
│   ├── lesson/*.html           # общий каркас урока + разделы (overview, theory, texts, vocab, tasks)
│   ├── partials/               # lesson_side, lesson_tree, exercise_list, ring, popover…
│   └── (остальные — переоформление)
├── routes/lessons.py           # /, /lessons, /lessons/{n}/vocab, соседи
├── routes/elements.py          # фрагмент, ⚙ / ⓘ, стрелки
├── routes/topics.py            # вкладки темы
├── routes/vocab.py             # /practice хаб, /practice/setup, вид списка, тема
└── today.py                    # данные «Сегодня» (новый модуль)
src/french_learning/content/index.py   # neighbours(), lesson_tree(), topic_tabs()
```

**Structure Decision**: логика экранов, которой ещё нет («Сегодня», соседи, дерево урока,
вкладки темы), — в `content/index.py` и новом `web/today.py`. Остальное — шаблоны и CSS.
Шаблоны урока собираются в папку `templates/lesson/`.
