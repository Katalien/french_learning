# Contract: страницы после редизайна

Изменения относительно 001–004. Все прочие адреса работают как раньше (FR-042).

| Адрес | Было | Стало |
|---|---|---|
| `GET /` | список уроков | экран «Сегодня»: повторение, домашка двух последних уроков, тренажёры «пора» (FR-003) |
| `GET /lessons` | — | список уроков (новый) |
| `GET /lessons/{n}` | сводка + дубли разделов + медиа | «Обзор»: дата, темы, счётчики; панель разделов сбоку; «⚙ Настройки урока» (FR-010, FR-013) |
| `GET /lessons/{n}/theory` | теория + лексика | только теория; оглавление по всем теориям (FR-011, FR-030) |
| `GET /lessons/{n}/texts` | тексты | тексты; оглавление по всем текстам (FR-030) |
| `GET /lessons/{n}/vocab` | — | «Лексика»: новые слова, повторение, «Повторить слова урока» (FR-011) |
| `GET /lessons/{n}/tasks?part=` | задания | задания в выбранном виде (список / плитки) + «Медиаматериалы» (FR-012, FR-020a) |
| `GET /elements/{id}` | упражнение / теория / текст | упражнение: путь, темы один раз, «⚙», «ⓘ», ‹ ›, «☰ Урок», «Теория рядом» (FR-021–FR-025, FR-032) |
| `GET /elements/{id}?fragment=1` | — | тело теории / текста для второй половины экрана (FR-032) |
| `GET /topics/{id}?tab=` | один список | вкладки Теория / Тексты / Задания / Слова; «Повторить слова темы» (FR-040) |
| `GET /practice` | настройка повторения | хаб «Практика»: повторение, мои ошибки, тренажёры (FR-041) |
| `GET /practice/setup` | — | прежняя страница настройки повторения |
| `GET /vocab` | словарь + кнопка «Повторение» | словарь строками, без кнопки повторения (FR-041) |
| `POST /settings/theme` | — | cookie `theme` = light / dark / system (FR-004) |
| `GET/POST /settings` | порции, направления, голос | + вид списка заданий, оформление (FR-020a, FR-004) |

Шапка на всех страницах: «Уроки» (`/lessons`), «Словарь», «Практика», «Темы», меню «⋯»
(доп. материалы, «Требует проверки», сообщения, настройки, происхождение, оформление).
