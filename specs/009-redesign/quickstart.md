# Quickstart: проверка редизайна

```bash
uv run pytest
uv run french-learning serve
```

Смотреть на ширине компьютера и в эмуляции телефона (375 px), в светлой и тёмной теме.
Ориентир вида — [mockups/final.html](mockups/final.html) и [design.md](design.md).

1. **Шапка и «Сегодня» (US1)**: в шапке 4 раздела и «⋯»; на «Сегодня» — повторение,
   домашка двух последних уроков, тренажёры «пора»; нет списка уроков и ошибок. «⋯» →
   тёмная тема → перезагрузка → тема сохранилась.
2. **Урок (US2)**: урок 14 — панель разделов сбоку, закрывается и при следующем входе
   открыта; дублей нет; «Лексика» — слова и «Повторить слова урока»; медиа — внизу
   «Заданий»; «⚙» — дата и «требует проверки».
3. **Упражнение (US3)**: в списке номер один раз, строка — описание, под ней тема и тип;
   на странице — путь, темы один раз, «⚙» (статус, лист, оригинал, темы, сообщение), «ⓘ»
   (происхождение); ‹ › ведут к соседям; «☰ Урок 14» — дерево урока с ✓.
4. **Теория (US4)**: урок с двумя теориями — оглавление слева, переход ко второй без
   прокрутки; таблицы выделены; в упражнении «Теория рядом» — экран пополам, «✕» закрывает;
   проверка работает в разделённом режиме.
5. **Тема (US5)**: вкладки со счётчиками, пустых нет; «Слова» → «Повторить слова темы».
6. **Практика (US6)**: три блока; «Повторить» запускает «пора сегодня»; в «Словаре» кнопки
   повторения нет; старые адреса `/trainers`, `/mistakes` открываются.
7. **Оформление (US7)**: палитра «Перелив», Inter + Lora, лавандовые французские слова,
   главная кнопка с переливом, карточка «чистая» с широкой полосой рода; «Настройки» →
   вид списка «плитки» → список заданий плитками.
8. **Регрессия (SC-007)**: сценарии quickstart 001–004 выполняются как раньше.
