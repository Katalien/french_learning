# Quickstart: приёмка функции 002 на настоящих уроках

## Подготовка (один раз)

1. Функция 001 работает (`uv run french-learning serve`).
2. Хранилище: `C:\Users\Kate\source\french_learning_materials` (приватный репозиторий,
   склонирован). Подготовить его:

```bash
uv run french-learning init-content C:/Users/Kate/source/french_learning_materials
```

3. В `.env`:

```
CONTENT_DIR=C:/Users/Kate/source/french_learning_materials
SOURCE_MATERIALS_DIR=C:/Users/Kate/Documents/french_learning_materials
```

## Автоматические проверки

```bash
uv run pytest
```

## Сценарий приёмки

| # | Действие в Claude Code | Ожидаемый результат |
|---|---|---|
| 1 | `/add-lesson "…/Leçon 14"` | Опись: каждый файл с классификацией и будущими элементами, предложенная дата, вопросы |
| 2 | Ответить: дата, «добавь всё» | Отчёт по формату; коммит и отправка в `french_learning_materials` |
| 3 | Открыть приложение → урок 14 | Теория, текст «Au restaurant», задания «В классе» / «Домашка», лексика |
| 4 | Проверить листы: `IMG_3874` → 4 упражнения; `IMG_3765` → упражнение + справка; `IMG_3864` → текст + 2 упражнения; `IMG_3334` → «по картинке» с исходником | Совпадает |
| 5 | `/add-lesson "…/Leçon 13"` с выбором «домашка: только 1 и 3» | Остальные упражнения домашки — в «Резерве» |
| 6 | Запустить `/add-lesson "…/Leçon 14"` снова без изменений | «Новых файлов нет», контент не изменился (SC-006) |
| 7 | `/add-lesson урок 14: <файл> — это теория` | Элементы только этого файла заменены |
| 8 | В приложении — «Сообщить об ошибке», затем `/fix-reports` | Сообщение закрыто с пояснением |
| 9 | `/add-material <ссылка> правило про …` | Элемент в «Дополнительных материалах» со ссылкой |
| 10 | Открыть `lessons/014/inventory.md` и `index.md` в хранилище | Опись и указатель актуальны |
| 11 | `uv run french-learning quality-sample --lesson 13 --lesson 14` → сверить пункты с оригиналами | Ошибок ≤ 5% среди пунктов без «требует проверки» (SC-005) |
| 12 | `git status` в репозитории кода | Ни одного файла контента |
