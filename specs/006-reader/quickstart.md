# Quickstart: проверка «Чтения с переводом» (006)

Демо-хранилище, порт 8010 (как в 005). Интернет нужен для MyMemory, кроме пунктов «без сети».

```bash
uv run pytest
```

## 1. Перевод (US1)

1. Текст урока: выделить слово в форме (`commande`) → подсказка: слово, перевод,
   «Начальная форма: commander — …», 🔊, «+ В словарь: commander», ниже «пометка · вопрос».
2. Выделить полслова → выделение расширилось до слова.
3. Выделить предложение без точки и два предложения → перевод целиком; у двух предложений
   нет «+ В словарь».
4. Выделить слово из словаря → «✓ в словаре: …», запроса к сервису нет (журнал сервера).
5. Повторно выделить уже переведённое → мгновенно, из запаса.
6. Выключить сеть → новое слово: «Перевод сейчас недоступен», форма и 🔊 работают;
   переведённое раньше — из запаса.
7. Выделить русский текст → перевода нет (в уроке — только «пометка · вопрос»).
8. Упражнение, словарь, карточка, тема, доп. материал — подсказка с переводом тоже есть.

## 2. В словарь (US2)

1. «+ В словарь: commander» → «✓ в словаре: …»; в словаре запись с примером и уроком
   в «Подробнее», без темы; на обороте карточки — пример.
2. Фраза / предложение → запись вида «фраза».
3. Повторное добавление → дубль не создан.
4. «Происхождение: везде» → у перевода видно «внешний сервис».

## 3. Озвучка (US3)

🔊 в подсказке — слово, фраза, предложение; без сети тоже.

## 4. Переключатель (US4)

«⋯» → «Перевод при выделении: выкл» → в тексте урока только «пометка · вопрос»,
в словаре подсказки нет; после перезапуска приложения выбор сохранён.

## 5. Настройки

MyMemory / DeepL (без ключа — сообщение), почта для MyMemory, «Очистить запас» → 0 записей.

## 6. Начальная форма (SC-005)

10 глагольных и именных форм из текстов демо и уроков — не меньше 9 верных.

## 7. Вид

Светлая и тёмная тема, 375 px: подсказка не шире экрана.
