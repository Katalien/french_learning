# Quickstart: проверка «Поиска» (007)

Демо-хранилище, порт 8010 (`uv run french-learning serve --port 8010 --content-dir <демо>`).
Интернет не нужен.

```bash
uv run pytest
```

## 1. По мере ввода (US1)

1. На любой странице (урок, словарь, тема) — строка поиска в шапке на одном месте.
2. Ввести `m` → «Введите хотя бы 2 буквы»; `ma` → появились группы; дописать до `maison` —
   результаты уточняются без Enter.
3. `mang` находит слова на `mang…`; `ange` — не находит `manger`.
4. `francais`, `Maison`, `ete`, `oeuf` / `œuf`, `l’eau` / `l'eau` / `eau`, `peut etre` —
   находят соответствующие слова; по-русски `дом`, `ёж` / `еж` — тоже.
5. `il y a` находит теорию с «il y a» и «il y avait».
6. `la` — слова словаря не находятся (только по артиклю), теория — да.
7. `zzz` — «Ничего не найдено». Скрытое слово словаря не находится.

## 2. Область и фильтры (US2)

`maison` → «Словарь» — только слова → урок N — только слова урока N → «Всё» — снова все
группы. Закрыть панель (Esc) и открыть снова — область «Всё», фильтры сброшены.

## 3. Переход (US3)

Результат теории → страница теории прокручена к первому совпадению, все совпадения
подсвечены; «Следующее ↓» переходит дальше; «Снять подсветку» убирает метки; «← к результатам»
возвращает к странице результатов. Слово → страница слова; тема «Лексика» → вкладка «Слова».
Отметки заметок (005) на странице остаются.

## 4. Фрагмент (US4)

`h aspire` → у результата теории фрагмент с выделенными словами и «ещё N», если совпадений
несколько.

## 5. Страница результатов

Enter в строке → `/search?q=…`: группы блоками, все результаты, область и фильтры сверху.
«Показать все (N)» у группы → та же страница с областью группы.

## 6. Настройки и вид

«Настройки» → снять «Показывать перевод у найденных слов» → у слов в результатах перевода нет.
Светлая и тёмная тема; 375 px — строка и панель во всю ширину.

## 7. Без перезапуска

Добавить слово в словарь (или «+ В словарь» из текста, 006) → оно сразу находится.
