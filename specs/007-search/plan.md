## Summary

Строка поиска в шапке на всех страницах. По мере ввода (от 2 символов) под ней открывается
панель:
- группы «Слова», «Темы», «Теория» по 3 результата, «Показать все (N)», «Все результаты»;
- над группами — область «Всё · Словарь · Теория · Темы» и фильтры по уроку и теме.

Enter открывает страницу со всеми результатами. Ищется по словарю (слово с артиклем
и переводы), теории (название и текст) и темам (название):
- по началу слова и фразами;
- без учёта регистра, акцентов, `œ`/`oe`, апострофов, дефисов и «ё»;
- на двух языках сразу.

Индекс строится в памяти для текущей версии контента и сам обновляется при правках.
Результат теории открывает страницу с подсветкой всех совпадений. У найденных слов виден
перевод, в настройках его можно скрыть.

## Technical Context

**Language/Version**: Python 3.12 (uv)

**Primary Dependencies**: без новых зависимостей — `unicodedata`, `html.parser`, уже
подключённые `markdown-it-py`, FastAPI, Jinja, HTMX, Alpine.js

**Storage**: индекс — в памяти (кеш на объект `ContentIndex`, research R1); настройка
`search_translations` в `settings` базы прогресса (схема не меняется); история запросов
не хранится

**Testing**: pytest, TDD для:
- нормализации и разбиения на слова с позициями;
- совпадения (начало слова, фраза, последнее слово по началу);
- «только артикль» — без слов словаря;
- индекса (поля по видам, скрытые слова, теория из markdown без разметки);
- ранжирования, области и фильтров;
- фрагмента и счётчика;
- маршрутов `/search`, `/search/panel` и настройки;
- производительности на синтетическом наборе (SC-001).

JS (подсветка) — по quickstart.

**Target Platform**: браузер компьютера; телефон — вёрстка 375 px

**Performance Goals**: ответ `/search/panel` < 100 мс на 50 уроках и 5000 словах
(SC-001: < 0,3 с с учётом задержки ввода 150 мс)

**Constraints**:
- без интернета (IX);
- без хранения запросов (FR-014);
- поиск только читает контент

**Scale/Scope**:
- пакет `search/` (~3 модуля);
- 2 маршрута и настройка;
- 2 шаблона и правка шапки;
- 1 JS-модуль;
- ~40 тестов

**Structure Decision**: поиск — отдельный пакет `search/`, как `notes/` и `translate/`.
Он читает `ContentIndex` и ничего не пишет. Разметку результатов рисует сервер: один
частичный шаблон групп для панели и страницы.
