# Feature Specification: Поиск

**Feature Branch**: `007-search`

**Created**: 2026-09-29

**Status**: Clarified

**Input**: Ответы пользователя 2026-09-29: «Искать по теории, темам и словарю. Желательно
разделять поиск: если ввожу maison — хочу ли я найти слово в словаре или слова урока по этой
теме, но без нескольких значков поиска. Искать на обоих языках, динамически по началу слова
и по слову целиком, без форм слова, без учёта акцентов, фразами. Строка в шапке или значок,
раскрывающий строку, — посмотреть варианты. Результаты группами, фильтры по уроку и теме.
Переход к найденному месту с подсветкой. Для слов — сразу перевод (или настройкой). Если
ничего нет — „Ничего не найдено“. Историю запросов не хранить.»

## Границы функции

- **Входит**: одна точка входа в поиск на всех страницах; поиск по мере ввода; по теории
  (названия и текст), темам (названия) и словарю (французское слово с артиклем и переводы);
  без учёта регистра, акцентов и вида апострофа; фразы из нескольких слов; результаты
  группами; область поиска и фильтры по уроку и теме; переход к найденному месту с подсветкой;
  перевод слова прямо в результатах.
- **Не входит**: поиск по текстам уроков, упражнениям, ответам и заданиям тренажёров
  (позже); по заметкам (подключит функция 005); формы слова (`prendre` → `pris`);
  история запросов; поиск в интернете или словарях вне приложения.

## Clarifications

### Session 2026-09-29

- Q: Где вход в поиск? → A: Строка поиска всегда в шапке (макет, вариант А «строка в шапке»).
- Q: Как показывать результаты? → A: Панель под строкой: группы «Слова / Темы / Теория» по 3
  результата, «Показать все (N)» у группы и ссылка «Все результаты» внизу; под строкой в панели —
  область «Всё · Словарь · Теория · Темы» и фильтры урок / тема.
- Q: Показывать ли фрагмент теории с подсветкой? → A: Да.
- Q: Показывать ли перевод у найденных слов? → A: Да (по умолчанию; выключается в «Настройках»).
- Q: Что делает Enter в строке поиска? → A: Открывает страницу со всеми результатами —
  группы блоками, с той же областью и фильтрами.
- Q: Искать ли скрытые слова словаря? → A: Нет.

## User Scenarios & Testing *(mandatory)*

### User Story 1 - Найти по мере ввода (Priority: P1)

Пользователь с любой страницы открывает поиск и начинает печатать `mais`. Сразу появляются
результаты, сгруппированные по видам: «Слова» (`la maison` — дом), «Темы» («Дом»),
«Теория» (правило, где встречается `maison`). Акценты и регистр не важны: `ete` находит
`été`, `Francais` находит `français`; по-русски `дом` находит `la maison`.

**Why this priority**: основная ценность функции — быстро найти нужное без перебора уроков.

**Independent Test**: на любой странице открыть поиск → ввести `mais` → через мгновение видны
группы «Слова», «Темы», «Теория» с найденным; дописать до `maison` — результаты уточняются;
ввести `дом` — находится `la maison`; ввести `ete` — находится `été`.

**Acceptance Scenarios**:

1. **Given** любая страница приложения, **When** пользователь открывает поиск, **Then** это
   одна и та же точка входа (одна строка или один значок) на всех страницах.
2. **Given** в строке поиска 2 символа или больше, **When** пользователь печатает, **Then**
   результаты обновляются по мере ввода, без нажатия Enter.
3. **Given** запрос `mang`, **When** выполняется поиск, **Then** находятся слова, начинающиеся
   на `mang` (`manger`, `la mangue`); запрос `ange` не находит `manger` (совпадение только
   с начала слова).
4. **Given** запрос без акцентов `francais` или с заглавной буквы `Maison`, **When** выполняется
   поиск, **Then** находятся `français` и `maison`; `œ` и `oe`, разные апострофы считаются
   одинаковыми.
5. **Given** запрос по-русски `дом`, **When** выполняется поиск, **Then** находятся слова
   с переводом «дом», тема «Дом» и теория, где встречается «дом»; «ё» и «е» не различаются.
6. **Given** фраза `il y a`, **When** выполняется поиск, **Then** находятся места, где эти
   слова идут подряд (последнее слово — по началу: `il y a` находит и `il y avait`).
7. **Given** найдено слово словаря, **When** показаны результаты, **Then** рядом со словом
   виден перевод (если в настройках не выключено).
8. **Given** ничего не найдено, **When** показаны результаты, **Then** выводится «Ничего
   не найдено».

---

### User Story 2 - Уточнить, где искать (Priority: P1)

Пользователь ищет `maison` и хочет видеть только слова словаря — или только теорию, или
только слова одного урока. Прямо под строкой поиска он переключает область («Всё · Словарь ·
Теория · Темы») и при необходимости выбирает урок и тему.

**Why this priority**: пожелание пользователя — разделять поиск без нескольких значков.

**Independent Test**: запрос `maison` → область «Словарь» → остались только слова → фильтр
«Урок 14» → только слова урока 14 → область «Всё» → снова все группы.

**Acceptance Scenarios**:

1. **Given** поиск открыт, **When** пользователь выбирает область «Словарь», «Теория» или
   «Темы», **Then** показываются результаты только этого вида; «Всё» — все группы.
2. **Given** фильтр «Урок N», **When** выполняется поиск, **Then** слова — только связанные
   с уроком N, теория — только урока N, темы — только встречающиеся в уроке N.
3. **Given** фильтр по теме, **When** выполняется поиск, **Then** остаются слова и теория
   этой темы.
4. **Given** пользователь закрыл и снова открыл поиск, **When** он смотрит на область
   и фильтры, **Then** они сброшены на «Всё» (история и выбор не запоминаются).

---

### User Story 3 - Перейти к найденному (Priority: P2)

Пользователь нажимает на результат из теории — открывается страница теории, прокрученная
к найденному месту, найденные слова подсвечены. Слово ведёт на страницу слова, тема — на
страницу темы (для тем раздела «Лексика» — на вкладку «Слова»).

**Why this priority**: без перехода к месту в длинной теории поиск полезен вдвое меньше.

**Independent Test**: запрос `partitif` → результат из теории урока 14 → страница
открылась на нужном абзаце, `partitif` выделен.

**Acceptance Scenarios**:

1. **Given** результат из теории, **When** пользователь его выбирает, **Then** открывается
   теория, страница прокручена к первому совпадению, все совпадения на странице подсвечены.
2. **Given** результат-слово, **When** пользователь его выбирает, **Then** открывается
   страница слова.
3. **Given** результат-тема, **When** пользователь его выбирает, **Then** открывается
   страница темы.
4. **Given** подсветка на странице теории, **When** пользователь продолжает чтение, **Then**
   подсветку можно убрать (например, кнопкой «Снять подсветку» или новым переходом).

---

### User Story 4 - Видеть найденное в контексте (Priority: P3)

У результатов из теории виден короткий фрагмент текста вокруг совпадения с выделенным
найденным словом — чтобы понять, то ли это место, до перехода.

**Why this priority**: удобство; решение об оформлении — по макетам.

**Independent Test**: запрос `h aspiré` → у результата теории виден фрагмент «… перед h
aspiré элизии нет …» с выделенными словами.

**Acceptance Scenarios**:

1. **Given** результат из теории, **When** он показан, **Then** виден фрагмент до ~20 слов
   вокруг совпадения с выделенным найденным (если вариант выбран по макету).
2. **Given** в теории несколько совпадений, **When** показан результат, **Then** указано,
   сколько их, и показан первый фрагмент.

---

### Edge Cases

- Запрос короче 2 символов — результатов нет, подсказка «Введите хотя бы 2 буквы».
- Много совпадений в группе — показываются первые (например, 5), кнопка «Показать все (N)».
- Запрос из знаков препинания или пробелов — как пустой.
- Скрытые слова словаря — не находятся (уточнение 2026-09-29).
- Слово с апострофом: `l'eau` находится по `eau`, по `l'eau` и по `l’eau`; слово с дефисом
  `peut-être` — по `peut`, `peut-être`, `peut etre`.
- Совпадение в разметке теории (таблица, заголовок, список) — находится, фрагмент без разметки.
- Совпадение в названии теории важнее, чем в тексте (показывается выше).
- Слово, совпадающее с артиклем (`la`, `le`, `les`), — по одному артиклю слова не ищутся
  (иначе нашлись бы все слова); в теории — ищутся как обычные слова.

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: Строка поиска ДОЛЖНА быть в шапке на всех страницах; при вводе под ней
  открывается панель результатов, Esc и щелчок вне панели её закрывают.
- **FR-002**: Результаты ДОЛЖНЫ обновляться по мере ввода, начиная с 2 символов.
- **FR-003**: Совпадение ДОЛЖНО засчитываться, если слово документа начинается с введённого
  слова запроса; слово целиком — частный случай.
- **FR-004**: Сравнение ДОЛЖНО не учитывать регистр, диакритику, `œ`/`oe`, `æ`/`ae`, вид
  апострофа, дефис как разделитель, «ё»/«е».
- **FR-005**: Запрос из нескольких слов ДОЛЖЕН находить места, где слова идут подряд;
  последнее слово — по началу.
- **FR-006**: Поиск ДОЛЖЕН идти на французском и русском одновременно (без выбора языка).
- **FR-007**: Искать ДОЛЖНО в: словаре — французское слово с артиклем и переводы;
  теории — название и текст; темах — название.
- **FR-008**: Результаты ДОЛЖНЫ быть сгруппированы: «Слова», «Темы», «Теория» со счётчиками;
  в панели — по 3 в группе, «Показать все (N)» и «Все результаты»; Enter и «Все результаты»
  открывают страницу результатов с группами блоками (все найденные).
- **FR-009**: ДОЛЖНА быть область поиска «Всё · Словарь · Теория · Темы» рядом со строкой
  поиска и фильтры по уроку и теме; при новом открытии поиска они сброшены.
- **FR-010**: У найденного слова ДОЛЖЕН быть виден перевод; в «Настройках» его можно скрыть.
- **FR-011**: Переход к результату из теории ДОЛЖЕН открывать теорию на первом совпадении
  с подсветкой всех совпадений; подсветку можно снять.
- **FR-012**: У результатов теории ДОЛЖЕН показываться фрагмент вокруг первого совпадения
  с выделенным найденным и число совпадений.
- **FR-013**: Если ничего не найдено — «Ничего не найдено».
- **FR-014**: История запросов НЕ ДОЛЖНА храниться.
- **FR-015**: Поиск ДОЛЖЕН работать без интернета (конституция IX).
- **FR-016**: Поиск ДОЛЖЕН учитывать правки контента (новые слова, уроки) без перезапуска
  приложения.

### Key Entities

- **Запрос**: текст, область (всё / словарь / теория / темы), фильтры (урок, тема).
- **Результат**: вид (слово / тема / теория), ссылка, заголовок, для слова — перевод, для
  теории — фрагмент и число совпадений.
- **Поисковый индекс**: нормализованные слова элементов (слово, переводы, название, текст),
  перестраивается при изменении контента.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: Результаты появляются не позже чем через 0,3 с после ввода символа на объёме
  контента до 50 уроков и 5000 слов.
- **SC-002**: На наборе контрольных запросов (акценты, регистр, апострофы, дефисы, «ё»,
  фразы, начало слова, русский) находятся 100% ожидаемых элементов и нет находок только
  по артиклю.
- **SC-003**: От любой страницы до найденного места в теории — не больше 2 действий
  (ввести запрос, выбрать результат).
- **SC-004**: Пользователь выбрал оформление по макетам и подтвердил, что поиск удобен.

## Assumptions

- Объём контента небольшой (десятки уроков, тысячи слов) — поиск считается в памяти
  приложения, отдельная поисковая система не нужна.
- Формы слова (спряжение, множественное число) не ищутся — только по началу слова; позже
  можно подключить формы из словаря.
- Порядок результатов в группе: совпадение с начала названия / слова выше совпадения
  в тексте; дальше — по номеру урока (новые сверху).
- Оформление выбрано по макету `mockups/index.html` (см. Clarifications); на узком экране
  строка поиска занимает всю ширину шапки, панель результатов — во всю ширину экрана.
