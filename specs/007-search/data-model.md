# Data Model: Поиск (007)

Поиск не хранит данных на диске: индекс — в памяти, история запросов не ведётся (FR-014).
Новая настройка — одна строка в `settings` базы прогресса (без смены схемы).

## Настройка

| ключ | значения | по умолчанию |
|---|---|---|
| `search_translations` | `1` / `0` | `1` — показывать перевод у найденных слов |

## Слово документа (`search/text.py`)

`Token(norm: str, start: int, end: int)` — нормализованное слово (research R2) и его место
в исходном тексте поля.

## Документ индекса (`search/index.py`)

| поле | тип | смысл |
|---|---|---|
| `kind` | `word` \| `topic` \| `theory` | группа результата |
| `id` | str | id элемента или темы |
| `title` | str | слово с артиклем / название темы / название теории |
| `url` | str | `/vocab/<id>`, `/topics/<id>`, `/elements/<id>` |
| `fields` | list[`Field`] | где искать: `Field(name, text, tokens)` |
| `translation` | str \| None | для слова — переводы через «, » |
| `lessons` | set[int] | уроки для фильтра (research R6) |
| `topics` | set[str] | темы для фильтра |
| `lesson_order` | int | для сортировки (новые уроки выше) |

Поля по видам: слово — `fr` (с артиклем), `ru` (каждый перевод — отдельное поле);
теория — `title`, `text` (текст отрендеренного markdown); тема — `title`.
Скрытые слова в индекс не попадают.

## Запрос (`search/query.py`)

| поле | тип | правило |
|---|---|---|
| `q` | str | нормализуется; меньше 2 символов → пустой запрос |
| `scope` | `all` \| `words` \| `theory` \| `topics` | иначе `all` |
| `lesson` | int \| None | фильтр урока |
| `topic` | str \| None | фильтр темы |

## Результат

| поле | тип | смысл |
|---|---|---|
| `kind`, `id`, `title`, `url` | — | из документа |
| `translation` | str \| None | для слова (если настройка включена) |
| `snippet` | list[(str, bool)] \| None | для теории: кусочки фрагмента ~20 слов, `True` — найденное |
| `count` | int | для теории: число совпадений в тексте |
| `rank` | tuple | порядок внутри группы (research R5) |

`SearchResults`: `groups` — `{"words": […], "topics": […], "theory": […]}` (уже с областью
и фильтрами), `total`, `empty_reason` — `short` («Введите хотя бы 2 буквы») / `none`
(«Ничего не найдено») / `None`.
