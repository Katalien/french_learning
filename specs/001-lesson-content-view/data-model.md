# Data Model: Формат, хранилище и просмотр уроков

Сущности функции 001 и правила их проверки. Точный формат файлов —
[contracts/content-format.md](contracts/content-format.md). Поля, нужные функциям 002–004,
включены сразу (необязательными), чтобы не менять формат без необходимости.

## Общие типы

| Тип | Значения / правила |
|---|---|
| `Id` | `^(les|th|tx|ex|voc|top|rep)-[a-z2-7]{8}$`; уникален во всём хранилище; не меняется |
| `Part` | `class` (в классе) · `homework` (домашка) |
| `Origin` | `material` (материал урока) · `external` (внешний ресурс) · `user` (добавлено вручную) · `ai` (создано ИИ) · `service` (внешний сервис) |
| `Status` | `main` (основное) · `optional` (необязательное) · `reserve` (резерв) |
| `NeedsReview` | `{flag: bool, note: str}` — `note` обязателен, если `flag = true` |
| `SourceRef` | `{file: путь внутри хранилища к сжатой копии, original: имя исходного файла, page: int?}` или `{url: str}` для внешнего ресурса |

## Урок (`Lesson`)

| Поле | Тип | Правила |
|---|---|---|
| `id` | Id (`les-…`) | |
| `number` | int ≥ 1 | уникален; берётся из `Leçon NN` |
| `date` | дата? | может отсутствовать → «дата не указана» |
| `source_folder` | str | имя папки исходных материалов |
| `media` | список `Media` | аудио / видео, только записи |

**Вычисляемые (не хранятся)**: темы урока = объединение тем всех элементов урока;
новые слова; счётчики домашки; число «требует проверки».

## Медиафайл (`Media`)

`name` (str) · `type` (`audio`|`video`) · `part` (Part) · `path` (путь к оригиналу
в папке материалов пользователя).

## Общие поля элемента контента (`ElementBase`)

| Поле | Тип | Правила |
|---|---|---|
| `id` | Id | |
| `kind` | `theory`·`text`·`exercise`·`vocab` | |
| `lesson` | int? | номер урока; нет → «Дополнительные материалы» |
| `part` | Part? | обязательно, если есть `lesson` (кроме `vocab`) |
| `topics` | список Id (`top-…`), ≥ 1 | каждая тема должна существовать в справочнике; пусто → «Без темы» допускается только при `needs_review.flag = true` |
| `origin` | Origin | |
| `sources` | список SourceRef | ≥ 1, кроме `origin = user` |
| `needs_review` | NeedsReview | по умолчанию `flag = false` |

## Элемент теории (`Theory`) — `kind: theory`

Поля `ElementBase` + `title` (str) + тело Markdown (заголовки, списки, таблицы, выделения,
изображения из хранилища) + `links.exercises` (вычисляется обратно из упражнений).

## Текст (`Text`) — `kind: text`

Поля `ElementBase` + `title` (str, французский) + тело Markdown (французский текст).
Связанные упражнения вычисляются по полю `links.text` упражнений.

## Упражнение (`Exercise`) — `kind: exercise`

| Поле | Тип | Правила |
|---|---|---|
| `type` | см. таблицу типов | |
| `number` | int ≥ 1 | сквозной номер во вкладке; уникален в паре (урок, часть) |
| `sheet_number` | str? | номер на исходном листе («2», «b») |
| `description_ru` | str | краткое описание для названия |
| `instruction` | `{ru: str, original: str, original_lang: fr|en|ru, origin: Origin}` | `ru` — перевод, `original` — как в материале |
| `status` | Status | |
| `reference` | Markdown? | справка; скрыта по умолчанию |
| `links` | `{text: Id?, theory: Id?}` | ссылки должны существовать |
| `show_source` | bool | `true` для типа `picture` (исходник рядом) |
| `answers_origin` | Origin | по умолчанию для всех ответов; пункт может переопределить |
| `items` | список пунктов (≥ 1) | структура зависит от типа |

### Типы упражнений и пункты

| `type` | Название | Пункт | Ответ пункта |
|---|---|---|---|
| `gap_choice` | пропуск с выбором из списка | `text` с `{{N}}`; у упражнения общий `options` | `answers: {N: [допустимые]}`, каждый ответ ∈ `options` |
| `gap_input` | пропуск со свободным вводом | `text` с `{{N}}`, `hint`? («(parler)») | `answers: {N: [допустимые]}` |
| `multi_gap` | несколько пропусков в предложении | как `gap_input`, ≥ 2 пропуска | как `gap_input` |
| `transform` | трансформация предложения | `prompt` | `answers: [допустимые предложения]` |
| `true_false` | верно / неверно | `statement` | `answer: bool` |
| `choice` | выбор варианта | `question`, `options` (≥ 2) | `answer: [индексы верных]` |
| `two_forms` | выбор из двух форм | `text` с `{{1}}`, `forms: [a, b]` | `answers: {1: [форма]}` |
| `grouping` | распределение по группам | у упражнения `groups`; пункт — `word` | `answer: имя группы` |
| `picture` | по картинке | `prompt`? | `answers: [допустимые]` (может быть пусто) |
| `open` | открытый ответ | `prompt` | ответов нет |

Каждый пункт: `id` (локальный, `1…n`), `answers_origin`? (переопределение),
`needs_review`?.

**Проверки**: число `{{N}}` в тексте совпадает с ключами `answers`; для `gap_choice`
ответы входят в `options`; индексы `choice` в пределах вариантов; `picture` → `show_source`;
`open` → без ответов.

## Лексическая единица (`VocabEntry`) — `kind: vocab`

| Поле | Тип | Правила |
|---|---|---|
| `entry_type` | `word`·`verb`·`phrase` | |
| `text` | str | французский текст (словарная форма, без артикля) |
| `article` | `le`·`la`·`l'`·`les`? | определённый артикль |
| `gender` | `m`·`f`·`both`? | |
| `flags` | `{plural_only, h_aspire, irregular, reflexive}` (bool) | |
| `pos` | str? | часть речи |
| `translations` | список `{text, lesson?, origin}` (≥ 1) | переводы накапливаются |
| `forms` | `{feminine?, plural?, note?}` | для 003 |
| `verb` | `{group?, conjugation: {tense: {pronoun: form}}}` | для 003, времена расширяемы |
| `lessons` | список int | уроки, в **лексике** которых слово было |
| `examples` | список `{text, lesson?}` | |
| `notes` | str? | заметки пользователя (003) |
| `needs_completion` | bool | для 003 |

`lesson`/`part` из `ElementBase` для лексики не используются — связь через `lessons`.

**Правило «новое слово» (FR-039)**: слово новое для урока L, если `min(lessons) == L`;
иначе в уроке L оно «на повторение».

## Тема (`Topic`) и справочник (`topics.yaml`)

`sections`: список `{id: slug, name}` (грамматика, лексика, произношение …);
`topics`: список `{id: top-…, name, section}`. Имя темы уникально без учёта регистра.

**Переходы**: переименование — меняется `name`; объединение A → B — во всех элементах `A`
заменяется на `B`, запись `A` удаляется, одним коммитом.

## Сообщение об ошибке (`Report`) — `reports/rep-….yaml`

`id` · `element` (Id) · `item` (int?) · `comment` (str) · `created` (дата-время) ·
`status` (`open`→`fixed` | `rejected`) · `resolution` (str?, заполняет агент).

## Ошибка загрузки (`LoadError`) — не хранится

`path` · `element_id`? · `message` — показывается на месте элемента и в общем списке ошибок.

## Индекс (в памяти)

Строится из всех файлов: уроки по номеру; элементы по id; элементы по (уроку, части, виду);
темы → элементы; обратные связи текст / теория → упражнения; «требует проверки»; ошибки
загрузки. Перестраивается при изменении файлов (research R7).
