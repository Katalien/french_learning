# Contract: Страницы и действия приложения

Сервер отдаёт HTML-страницы и HTML-фрагменты (для HTMX). Все адреса — только на
`127.0.0.1`. Ответы на ошибки — понятная страница на русском, без технических деталей.

## Страницы

| Адрес | Что показывает | Требования |
|---|---|---|
| `GET /` | Список уроков (новые сверху) со сводкой; вход в темы, «Дополнительные материалы», «Требует проверки», «Сообщения об ошибках» со счётчиком открытых | FR-030, FR-031, FR-043 |
| `GET /lessons/{number}` | Сводка урока + разделы «Теория», «Тексты», «Задания»; медиафайлы | FR-031, FR-032, FR-036 |
| `GET /lessons/{number}/theory` | Элементы теории и лексика урока (новые / на повторение) | FR-033, FR-039 |
| `GET /lessons/{number}/texts` | Тексты для чтения со ссылками на упражнения | FR-037, FR-027 |
| `GET /lessons/{number}/tasks?part=class|homework` | Упражнения вкладки: «номер — тема — описание», «на листе: …», пометка «необязательное» | FR-022, FR-026 |
| `GET /lessons/{number}/reserve` | Упражнения в резерве | FR-026 |
| `GET /elements/{id}` | Элемент: теория, текст или упражнение (без ответов; справка скрыта; исходник рядом для `picture`) | FR-023–FR-025, FR-027 |
| `GET /topics` | Темы по разделам с числом элементов; «Без темы» | FR-035 |
| `GET /topics/{id}` | Все элементы темы с номером урока / пометкой «дополнительный материал» | FR-035, FR-038 |
| `GET /extras` | Элементы без урока | FR-038 |
| `GET /review` | Элементы «требует проверки» с пояснениями | FR-041 |
| `GET /reports` | Сообщения об ошибках (открытые сверху) | FR-042 |
| `GET /sources/{path}` | Сжатая копия исходника: изображение / PDF в браузере, docx — как HTML | FR-034 |
| `GET /problems` | Ошибки загрузки контента (файл, причина) | FR-005 |

## Действия (формы / HTMX, ответ — обновлённый фрагмент)

| Действие | Что делает | Требования |
|---|---|---|
| `POST /settings/origin` | Включить / выключить показ происхождения (cookie) | FR-040 |
| `POST /lessons/{number}/date` | Изменить дату урока | FR-012 |
| `POST /elements/{id}/topics` | Изменить темы элемента (выбор из справочника или новая тема) | FR-012, FR-013 |
| `POST /topics/{id}/rename` | Переименовать тему везде | FR-013 |
| `POST /topics/{id}/merge` | Объединить тему с другой | FR-014 |
| `POST /elements/{id}/verified` | Снять «требует проверки» (элемент или пункт) | FR-041 |
| `POST /elements/{id}/report` | Создать сообщение об ошибке; ответ содержит напоминание о разборе агентом | FR-042, FR-043 |

Каждое действие, меняющее контент, записывает файл атомарно и делает git-коммит
в хранилище контента; при ошибке записи пользователь видит сообщение, контент
не меняется.

## Поведение при проблемах

- Хранилище не настроено / не найдено → страница с объяснением, где задать `CONTENT_DIR`.
- Повреждённый элемент → на его месте карточка «ошибка в данных» со ссылкой на `/problems`.
- Нет исходника → «оригинал недоступен», элемент показывается.
