# Quickstart: запуск и проверка функции 001

Сценарий, по которому пользователь принимает функцию. Детали форматов —
[contracts/content-format.md](contracts/content-format.md), адреса —
[contracts/ui-routes.md](contracts/ui-routes.md).

## Подготовка (один раз)

1. Установлены Python 3.12 и uv (уже есть).
2. Приёмка 001 идёт на **демо-хранилище**: синтетический урок из `tests/fixtures/content`
   копируется в отдельную папку `C:\Users\Kate\source\french_learning_demo`, где выполняется
   `git init` (правки из интерфейса делают коммиты). Настоящее хранилище
   `french_learning_materials` не затрагивается; первый настоящий урок появится при приёмке 002.
3. В корне проекта создан файл `.env` по образцу `.env.example`:
   `CONTENT_DIR=C:\Users\Kate\source\french_learning_demo`.
4. Установить зависимости и хуки:

```bash
uv sync
```

```bash
uv run pre-commit install --hook-type pre-commit --hook-type pre-push
```

## Автоматические проверки

```bash
uv run ruff check .
```

```bash
uv run pytest
```

Ожидается: ошибок линтера нет, все тесты проходят (на синтетическом образце).

## Проверка контента

```bash
uv run french-learning validate-content
```

Ожидается: одно нарушение — намеренно повреждённый элемент демо-урока (проверка изоляции
ошибок); остальное без нарушений.

## Запуск

```bash
uv run french-learning serve
```

Открыть `http://127.0.0.1:8000`.

## Ручная проверка (демо-уроки)

| # | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть главную | Список демо-уроков со сводкой: номер, дата, темы, новые слова, домашка «0 из N», «требует проверки» |
| 2 | Открыть демо-урок → «Задания» | Вкладки «В классе» / «Домашка»; названия «номер — тема — описание», «на листе: …» |
| 3 | Открыть упражнение с пропусками | Формулировка на русском, пункты на французском, ответов нет |
| 4 | Открыть упражнение со справкой | Справка скрыта, открывается по кнопке |
| 5 | Открыть упражнение «по картинке» | Исходный лист виден рядом |
| 6 | «Теория» | Правило с таблицей; «открыть оригинал» открывает PDF; лексика — «новые» и «на повторение» |
| 7 | «Тексты» | Текст для чтения отдельно от теории, ссылки на упражнения к нему |
| 8 | Темы → тема, общая для двух демо-уроков | Элементы из обоих уроков с номером урока |
| 9 | Переименовать тему | Новое имя видно везде; в хранилище контента появился коммит |
| 10 | Включить переключатель происхождения | Видны метки; у формулировки — оригинал |
| 11 | Раскрыть значок «требует проверки» | Пояснение агента; «отметить проверенным» снимает пометку |
| 12 | Отправить сообщение об ошибке | Напоминание о разборе агентом; счётчик на главной вырос |
| 13 | Сузить окно до 375 px | Всё читается без горизонтальной прокрутки |
| 14 | Испортить один файл упражнения вручную | На его месте «ошибка в данных», остальной урок работает; в `/problems` — причина |
| 15 | `git status` в репозитории кода | Ни одного файла контента |
