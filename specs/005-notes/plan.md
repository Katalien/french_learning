# Implementation Plan: Заметки

**Branch**: `005-notes` | **Date**: 2026-09-29 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `/specs/005-notes/spec.md`; макеты —
[mockups/v3.html](mockups/v3.html) (страницы элементов), [mockups/v6.html](mockups/v6.html)

## Summary

«Пометки на полях тетради» и вопросы к преподавательнице. Заметку можно привязать к уроку,
к элементу урока (текст, теория, упражнение) или к фрагменту текста внутри элемента.

Что делаем:
- **Хранение** — новая таблица `notes` в базе прогресса (схема v3). Попадает в ту же
  резервную копию, что и прогресс.
- **Сервер** — хранилище `NoteStore`, группировка для страницы урока, JSON API
  (создать, изменить, удалить), страница «Заметки к уроку», панель вопросов, счётчик
  в шапке.
- **Браузер**, два новых небольших модуля без сборки:
  - `selection.js` — подсказка у выделения. Сейчас в ней полоска «пометка · вопрос»,
    функция 006 добавит перевод;
  - `notes.js` — отметки фрагментов, поле справа по кнопке, одна заметка по щелчку,
    окна создания и правки, Enter / Shift+Enter.
- **Значки** «облачка-комментарии» — собственный SVG-спрайт в `base.html`.

Порядок работ изменён: 005 → 006 → 007. Поэтому подсказку при выделении впервые делает
эта функция (research R5).

## Technical Context

**Language/Version**: Python 3.12 (uv)

**Primary Dependencies**: без новых. FastAPI, Jinja2, HTMX, Alpine.js — как раньше; новый
JavaScript — свои файлы в `static/js/`

**Storage**: база прогресса SQLite, схема 2 → 3 (таблица `notes`, data-model.md);
резервная копия `backups/progress.sql` без изменений механизма

**Testing**: pytest, TDD для:
- хранения и правил (`NoteStore`: пустой текст, вид, «ответ закрывает вопрос»,
  привязки, запрет для дополнительных материалов);
- группировки страницы урока;
- API (коды ответов);
- миграции v2 → v3 с сохранением данных;
- попадания заметок в дамп;
- счётчика вопросов;
- разметки страниц (кнопки, JSON, блоки В1).

JS (якоря, поле, подсказка) проверяется по quickstart (принцип XIII)

**Target Platform**: браузер компьютера; телефон — вёрстка 375 px, выделение долгим нажатием

**Project Type**: функция веб-приложения (сервер + шаблоны + немного JS)

**Performance Goals**: страница элемента с 20 заметками — расстановка якорей < 50 мс;
счётчик «❓ N» — один запрос по индексу на страницу

**Constraints**: без интернета; без сборки фронтенда; личные данные не уходят
во внешние сервисы (IX, VI); поведение 001–004, 009 не меняется

**Scale/Scope**:
- 1 таблица, ~5 маршрутов;
- 2 JS-модуля (~400 строк);
- 1 новый шаблон и правки 5 шаблонов;
- ~40 тестов
