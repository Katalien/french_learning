# Quickstart: проверка функции «Заметки» (005)

Проверять на **демо-хранилище** (порт 8010), не на настоящем прогрессе пользователя.

```bash
uv run pytest
```

```bash
CONTENT_DIR=<папка демо-хранилища> uv run french-learning serve --port 8010
```

## 1. Пометка к фрагменту (US1)

1. Открыть текст урока. Выделить фразу, в полоске выбрать «пометка», написать текст, нажать
   Enter → фраза подчёркнута бледным пунктиром.
2. Перезагрузить страницу → отметка на месте. Щелчок по фразе → видна только эта заметка;
   щелчок мимо или Esc — закрывается.
3. Shift+Enter в поле — перенос строки, а не сохранение.
4. То же в упражнении: выделить слова в условии или в пункте.

## 2. Вопрос и ответ (US2)

1. Записать вопрос → в шапке значок «1».
2. Щелчок по значку → панель со ссылкой «↗» на место вопроса.
3. ✓ → поле ответа под вопросом → Enter → вопрос отвечен, значок в шапке исчез,
   ответ «→ …» виден под вопросом.
4. Снять отметку → вопрос снова открыт, ответ сохранён.
5. В правке вопроса вписать ответ → вопрос тоже отвечен.

## 3. Поле заметок (US3)

1. «[значок] 3» → справа поле: «Ко всему …» сверху, «К фрагментам» на уровне строк.
   Повторное нажатие — поле скрыто, текст во всю ширину.
2. Наведение на заметку подсвечивает фрагмент, и наоборот.
3. Важная заметка всегда под заголовком и на поле не дублируется.
4. Ширина 375 px (эмуляция телефона) → заметки списком над текстом, без горизонтальной
   прокрутки.

## 4. Заметка к элементу и уроку (US4) и страница урока (US5)

1. «＋» у заголовка → окно под кнопкой → заметка ко всему элементу.
2. Боковая панель урока → «Заметки N» → страница: слева «Спросить на уроке», справа
   «К уроку» и блоки элементов в порядке урока.
3. «+ Вопрос к уроку…» и «+ Пометка к уроку…» + Enter → заметка появилась в своём блоке.
4. Наведение на пометку к фрагменту → виден фрагмент; «↗» открывает элемент с этой заметкой.

## 5. Правка и удаление (US6)

1. ✎ → правка на месте → Enter. Вопрос остаётся в блоке вопросов.
2. 🗑 → подтверждение → заметка удалена, отметка во фрагменте снята.

## 6. Якоря (R2)

1. В демо-тексте, где одна фраза встречается дважды, поставить заметку на второе
   вхождение → после перезагрузки отмечено второе.
2. Изменить текст демо-урока вокруг фразы (не саму фразу) → отметка на месте.
3. Изменить саму фразу → заметка на поле с пометкой «место не найдено»; перепривязать её
   к новому выделению.

## 7. Хранение (SC-004)

1. Кнопка резервной копии (или ежедневная копия) → в `backups/progress.sql` есть таблица
   `notes`.
2. Выполнить `restore` на копии демо → заметки и отметки на месте.

## 8. Вид

Проверить светлую и тёмную тему: значки «облачка», пунктир, поле, панель вопросов,
страница урока.
