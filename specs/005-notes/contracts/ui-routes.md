# Contract: страницы и изменения интерфейса (005)

## Новые адреса

| адрес | что |
|---|---|
| `GET /lessons/{n}/notes` | страница «Заметки к уроку» (вариант В1): слева «Спросить на уроке», справа «К уроку» и блоки элементов; `?fragment=1` — только содержимое для HTMX |
| `GET /questions` | HTML-фрагмент панели открытых вопросов |
| `POST/PATCH/DELETE /notes…` | JSON API (`notes-api.md`) |

## Изменения существующих страниц

| где | что добавляется |
|---|---|
| `base.html` (шапка) | значок-вопрос «N» (только при N > 0) → панель вопросов; SVG-спрайт значков; `selection.js`, `notes.js` |
| `element.html` (текст, теория, упражнение урока) | у заголовка «＋» и «[значок] N»; строка важных заметок под заголовком; поле справа (по кнопке); `notes-data` JSON; якоря в теле; на узком экране — список над содержимым |
| `partials/reading.html` (разделы «Теория», «Тексты») | якоря и одна заметка по щелчку; создание через выделение; поля нет |
| фрагмент «Теория рядом» | якоря расставляются после подгрузки |
| `lesson_base.html` (боковая панель урока) | пункт «Заметки» с числом |
| меню урока «☰» на странице элемента | пункт «Заметки к уроку» |

## Поведение (сводка из spec)

- Выделение в контейнере элемента → полоска «пометка · вопрос» (секция 005 в `selection.js`)
  → окно под фрагментом.
- Щелчок по отметке → одна заметка сбоку (под фрагментом, если справа нет места);
  закрывается щелчком мимо или Esc.
- Enter — сохранить, Shift+Enter — перенос строки, Esc — отмена.
- 🗑 → подтверждение → удаление.
- Дополнительные материалы, словарь, тренажёры, темы — без изменений.
