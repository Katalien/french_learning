# Contract: JSON API заметок (005)

Доступен только локально, как всё приложение (принцип XII). Тела запросов и ответов — JSON,
кодировка UTF-8. Ошибки: `{"error": "текст по-русски"}`.

## Представление заметки

```json
{
  "id": 12, "kind": "question", "body": "pendant que или alors que?",
  "important": false, "answered": true, "answer": "время vs противопоставление",
  "lesson": 15, "element_id": "tx-aumarche", "element_title": "Au marché",
  "anchor": {"exact": "pendant que", "prefix": "au chocolat ", "suffix": " sa sœur", "start": 118},
  "created_at": "2026-09-29T10:15:00", "updated_at": "2026-09-29T11:02:00"
}
```

## `POST /notes` — создать

Тело: `kind`, `body`, `important?`, и одно из двух:
- `lesson` — заметка ко всему уроку;
- `element_id` (+ `anchor?`) — заметка к элементу или его фрагменту.

| ситуация | ответ |
|---|---|
| успех | `201` + заметка |
| пустой `body`, неизвестный `kind`, `anchor` без `element_id` | `422` |
| элемент не найден или это дополнительный материал | `422` «заметки есть только у элементов уроков» |
| урок не найден | `404` |

## `PATCH /notes/{id}` — изменить

Любое подмножество полей: `body`, `kind`, `important`, `answered`, `answer`, `anchor`
(перепривязка к новому выделению или `null` — ко всему элементу).

- непустой `answer` у вопроса → `answered = true`;
- `answered: false` → вопрос снова открыт, `answer` сохраняется;
- ответ `200` + заметка, `404` — нет такой заметки, `422` — нарушены правила data-model.

## `DELETE /notes/{id}`

`204`; `404` — нет такой заметки. Подтверждение удаления спрашивает интерфейс.

## `GET /questions` — панель открытых вопросов (HTML-фрагмент для HTMX)

Группы по урокам. У каждого вопроса есть ссылка «↗» туда, где он записан:
- `/elements/{id}#note-{id}` — заметка к элементу;
- `/lessons/{n}/notes` — заметка ко всему уроку.
