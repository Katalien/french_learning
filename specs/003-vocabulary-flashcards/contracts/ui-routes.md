# Contract: страницы и действия словаря

| Адрес | Что | Требования |
|---|---|---|
| `GET /vocab?kind=&lesson=&topic=&filter=known|hidden|incomplete&view=cards|list` | Список записей с фильтрами; счётчик «Нужно дополнить» и кнопка «Дополнить» | FR-010–FR-012, FR-023 |
| `GET /vocab/{id}` | Карточка записи: артикль, слово, род (цвет + m/f), часть речи, переводы, 🔊, доп. блок (формы, спряжение, заметки, уроки, пример) | FR-012–FR-014 |
| `POST /vocab/{id}/edit` | Правка полей и заметок | FR-050 |
| `POST /vocab/{id}/hide` · `/unhide` | Скрыть / вернуть запись из урока | FR-050 |
| `POST /vocab/{id}/delete` | Удалить свою запись (с подтверждением) | FR-050 |
| `POST /vocab/{id}/known` · `/unknown` | «Я это знаю» / вернуть | FR-051 |
| `GET /vocab/add` · `POST /vocab/add` | Одно слово: текст, переводы, вид, род, тема, урок | FR-020 |
| `POST /vocab/import` | Список: результат — добавлено / объединено / не распознано (для исправления) | FR-021, FR-022 |
| `GET /vocab/complete` | Сколько записей нужно дополнить и команда `/complete-words` | FR-024 |
| `GET /practice` | Настройка сеанса: режим, вид, направление, урок / тема, способ ответа; число карточек | FR-030, FR-031, FR-035 |
| `POST /practice/start` | Создать сеанс → первая карточка | FR-035b |
| `GET /practice/{session}` | Текущая карточка (вопрос) | FR-032 |
| `POST /practice/{session}/show` | Показать ответ + кнопки оценок | FR-032 |
| `POST /practice/{session}/rate` | Оценка → следующая карточка / итог порции | FR-034 |
| `POST /practice/{session}/answer` | Ввод ответа → результат или выбор написания | FR-041–FR-044 |
| `POST /practice/{session}/undo` | Отменить последнюю оценку | FR-033 |
| `GET /lessons/{n}/practice` | Повторить лексику урока (все слова, один сеанс) | FR-037 |
| `GET /settings` · `POST /settings` | Размер порции, режим направлений | FR-035a |
| `POST /backup` | Резервная копия прогресса сейчас; дата последней успешной отправки | FR-053 |

Панель символов и выбор написания — фрагменты HTMX; озвучка — `static/js/speech.js`.
