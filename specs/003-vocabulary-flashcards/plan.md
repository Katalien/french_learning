# Implementation Plan: Словарь и карточки

**Branch**: `003-vocabulary-flashcards` | **Date**: 2026-09-27 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `/specs/003-vocabulary-flashcards/spec.md`

## Summary

Вкладка «Словарь»: просмотр записей (слова, глаголы, фразы) с фильтрами и карточкой
(род цветом и меткой, свёрнутый доп. блок, озвучка), добавление слов по одному и списком
в мягком формате, правка / скрытие / удаление / «Знаю», дополнение агентом
(`/complete-words`). Повторение по FSRS в двух направлениях: режимы «пора сегодня», урок,
тема, все, сложные; порции; самооценка или ввод ответа с панелью французских символов
и выбором написания. Прогресс — SQLite с ежедневной текстовой резервной копией
в приватном хранилище.

Слова — это контент (файлы YAML, правки через `ContentWriter`, как в 001); прогресс
(карточки, оценки, сеансы, настройки) — SQLite. Проверка ответов — отдельный модуль,
который переиспользует функция 004.

## Technical Context

**Language/Version**: Python 3.12 (uv)

**Primary Dependencies**: существующие + `fsrs` (алгоритм повторения, MIT); SQLite —
стандартный модуль `sqlite3`; озвучка — Web Speech API браузера

**Storage**: словарь — `vocabulary/*.yaml` (формат v1 + необязательное поле `hidden`);
прогресс — `CONTENT_DIR/.progress/progress.sqlite`; копия — `backups/progress.sql`

**Testing**: pytest (TDD для проверки ответов, разбора списка, карточек и расписания,
сеансов, резервной копии, правок словаря); интерфейс — вручную по quickstart

**Target Platform**: как в 001 (локально, браузер, экран телефона)

**Project Type**: расширение веб-приложения + навык агента

**Performance Goals**: следующая карточка — мгновенно (< 200 мс) при словаре до 5000 записей

**Constraints**: без интернета (кроме отправки копии); история оценок не удаляется
(кроме отмены ошибочного нажатия в текущем сеансе); только локальный доступ

**Scale/Scope**: до тысяч записей, десятки тысяч оценок в год
