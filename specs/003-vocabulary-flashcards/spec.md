# Feature Specification: Словарь и карточки

**Feature Branch**: `003-vocabulary-flashcards`

**Created**: 2026-09-27

**Status**: Draft

**Input**: Описание пользователя (собрано из обсуждения): «У меня есть вкладка со словарём:
я просматриваю все слова, слова урока, слова темы; добавляю свои слова по одному или списком.
Кроме слов есть глаголы и целые фразы для разговорной речи. У слова несколько переводов,
артикль, род (цветом и меткой), часть речи; в дополнительном блоке — женский род и
множественное число, у глаголов группа и спряжение, мои заметки. Я повторяю карточки в обе
стороны: вспоминаю, открываю ответ и оцениваю себя — не помню / с трудом / помню. Есть режим
„пора повторить сегодня“, по урокам, по темам, сложные слова. Могу включить режим, где
печатаю ответ, — но на моей клавиатуре нет французских символов.» Подробности —
`docs/roadmap.md`, функция 003.

## Границы функции

- **Входит**: вкладка «Словарь» (просмотр, поиск по списку не входит — см. 007),
  три вида записей (слово, глагол, фраза), карточка с дополнительным блоком, ручное
  добавление по одной и списком, пометка «нужно дополнить» и дополнение агентом, правка /
  скрытие / удаление, повторение с интервальным алгоритмом в двух направлениях, режимы
  и фильтры повторения, режим ввода ответа, исключение из повторения, озвучка на карточке,
  история повторений, резервное копирование данных прогресса.
- **Не входит**: извлечение лексики из уроков (002), чтение текстов с переводом по выделению
  (006), сквозной поиск (007), статистика (008), спряжение в других временах кроме
  настоящего (формат допускает, реализация позже), тренажёры форм — спряжение, артикли
  (функция 004), картинка на карточке (идея на будущее,
  веха 4 в `docs/roadmap.md`).

## Clarifications

### Session 2026-09-27

- Q: Как повторять спряжение глаголов в словаре? → A: В словаре вспоминается только начальная
  (словарная) форма и перевод; спряжение — справка в дополнительном блоке. Тренажёры форм
  (спряжение, артикли и др.) — отдельный блок в упражнениях (функция 004). Отдельный
  «словарь глаголов» пока не делается: для повторения только глаголов используется фильтр
  вида; идея записана в дорожную карту.
- Q: Новое слово сразу попадает в повторение в обоих направлениях или сначала в одном? → A:
  По умолчанию сначала только FR → RU; карточка RU → FR добавляется, когда слово впервые
  отмечено «Помню» в FR → RU. Поведение меняется в настройках (например, «обе карточки
  сразу»).
- Q: Показывать много карточек одним сеансом или порциями? → A: Повторение, запущенное
  из урока, — все слова урока одним сеансом. Повторение из словаря — порциями по N карточек
  (N задаётся в настройках). Закончить можно в любой момент; прогресс по уже оценённым
  карточкам сохраняется.
- Q: Меняют ли расписание оценки в режимах, отличных от «Пора повторить сегодня»? → A: Да,
  любые оценки в любом режиме обновляют расписание; алгоритм учитывает повтор раньше срока.
- Q: Куда сохранять резервные копии прогресса? → A: В приватный репозиторий контента
  с отправкой на GitHub: автоматически раз в день (при запуске приложения) и вручную
  по кнопке.

## User Scenarios & Testing *(mandatory)*

### User Story 1 - Повторить карточки (Priority: P1)

Пользователь открывает вкладку «Словарь» → «Повторение», выбирает режим («пора повторить
сегодня», по уроку, по теме, все, сложные), что повторять (слова / глаголы / фразы / всё)
и направление (французский → русский или русский → французский). Для каждой карточки он
вспоминает ответ, нажимает «Показать», видит ответ и оценивает себя: «Не помню», «С трудом»,
«Помню». Алгоритм назначает следующий показ. Ошибочную оценку можно отменить.

**Why this priority**: ежедневное повторение — главная ценность словаря.

**Independent Test**: в хранилище 10 слов урока 14. Открыть «Пора повторить сегодня»,
направление FR → RU → пройти 10 карточек с разными оценками → на следующий день в режиме
«сегодня» появляются слова с оценкой «Не помню», а «Помню» — позже.

**Acceptance Scenarios**:

1. **Given** в словаре есть слова, **When** пользователь начинает повторение, **Then** он
   выбирает режим, вид записей (слова / глаголы / фразы / всё вместе) и направление.
2. **Given** показана карточка FR → RU с `la maison`, **When** пользователь нажимает
   «Показать», **Then** видны все переводы; только после этого доступны оценки «Не помню»,
   «С трудом», «Помню».
3. **Given** пользователь оценил карточку, **When** он понял, что ошибся с оценкой, **Then**
   кнопка «Отменить последнюю оценку» возвращает предыдущую карточку и её прежний прогресс.
4. **Given** слово хорошо известно в направлении FR → RU, но плохо в RU → FR, **When**
   пользователь повторяет в каждом направлении, **Then** прогресс и расписание ведутся
   отдельно для каждого направления.
5. **Given** на сегодня нет карточек к повторению, **When** пользователь выбирает «Пора
   повторить сегодня», **Then** приложение сообщает об этом и предлагает другие режимы.
6. **Given** в уроке 15 появились новые слова, **When** пользователь открывает «Пора
   повторить сегодня», **Then** новые слова включены автоматически, без ограничения
   по количеству, в направлении FR → RU (при настройке по умолчанию).
7. **Given** новое слово впервые оценено «Помню» в FR → RU, **When** пользователь открывает
   повторение RU → FR, **Then** карточка этого слова в направлении RU → FR появилась
   в расписании.
8. **Given** пользователь открыл урок (функция 001), **When** он нажимает «Повторить лексику
   урока», **Then** начинается повторение всех слов этого урока одним сеансом.
9. **Given** пользователь запустил «Пора повторить сегодня» из словаря и к повторению
   60 карточек, **When** сеанс идёт, **Then** карточки показываются порциями по N (из настроек),
   после порции можно продолжить или закончить.
10. **Given** пользователь оценил 7 карточек и закрыл повторение, **When** он возвращается,
    **Then** оценки 7 карточек сохранены, остальные остаются к повторению.

### User Story 2 - Просмотреть словарь и карточку слова (Priority: P2)

Пользователь открывает «Словарь» и просматривает все записи, либо записи урока, темы, вида
(слова / глаголы / фразы). Можно переключиться на быстрый просмотр списком «слово —
перевод». Открыв карточку, он видит артикль, слово, род (цвет и метку), часть речи, переводы,
кнопку 🔊; в свёрнутом дополнительном блоке — формы слова, спряжение глагола, заметки,
уроки, где слово встречалось, и пример.

**Why this priority**: без просмотра нельзя проверить и поправить словарь.

**Independent Test**: открыть словарь → отфильтровать по уроку 14 → переключиться на список
→ открыть карточку `la maison` → раскрыть дополнительный блок → увидеть формы и уроки.

**Acceptance Scenarios**:

1. **Given** в словаре есть записи из разных уроков и свои, **When** пользователь выбирает
   фильтр (все / урок / тема / вид), **Then** показываются только соответствующие записи.
2. **Given** открыт список, **When** пользователь переключает вид, **Then** доступен
   быстрый просмотр «слово — перевод» и вид карточек.
3. **Given** карточка существительного женского рода, **When** она показана, **Then** род
   виден меткой `f` и цветом женского рода; у мужского — метка `m` и свой цвет; у записей без
   рода — нейтральный цвет без метки.
4. **Given** карточка открыта, **When** пользователь раскрывает дополнительный блок, **Then**
   он видит: для существительных и прилагательных — женский род и множественное число
   с подсказкой, как они образуются; для глаголов — группу и спряжение в настоящем времени
   для всех местоимений; свои заметки; уроки, где запись встречалась; пример из урока.
5. **Given** карточка открыта, **When** пользователь нажимает 🔊, **Then** слово или фраза
   произносится по-французски.

### User Story 3 - Добавить свои слова по одному и списком (Priority: P3)

Пользователь добавляет запись вручную: слово, глагол или фразу с переводом(ами), темой и,
по желанию, уроком. Или вставляет список строк «французское — перевод» в мягком формате.
Незаполненные поля (род, формы, спряжение) помечаются «нужно дополнить»; пользователь
нажимает кнопку, и приложение подсказывает, как попросить агента дополнить записи.

**Why this priority**: словарь пополняется не только из уроков.

**Independent Test**: вставить список из 5 строк (`chat — кот`, `la maison — дом`,
`parler (v) — говорить`, `Ça va ? — Как дела?`, `l'eau (f) — вода`) → 5 записей созданы,
вид и род определены там, где указаны; остальное помечено «нужно дополнить» → попросить агента
дополнить → поля заполнены с пометкой ИИ.

**Acceptance Scenarios**:

1. **Given** пользователь добавляет запись вручную, **When** он указывает французский текст
   и хотя бы один перевод, **Then** запись сохраняется; остальные поля необязательны.
2. **Given** пользователь вставил список, **When** строки имеют вид «французское — перевод»
   (разделитель — тире или дефис с пробелами; несколько переводов через запятую), **Then**
   каждая строка становится записью.
3. **Given** строка содержит артикль `le`/`la` или пометку `(m)`/`(f)`, **When** она
   разбирается, **Then** род определяется по ним; пометки `(v)`, `(adj)`, `(phr)` задают
   вид / часть речи.
4. **Given** строка не распознана, **When** список обработан, **Then** такие строки показаны
   для исправления, а остальные добавлены.
5. **Given** в списке слово, которое уже есть в словаре, **When** список обработан, **Then**
   новый перевод добавляется к существующей записи (правила «одно слово — одна запись»),
   а пользователь видит, какие записи были объединены.
6. **Given** у записей есть незаполненные поля, **When** пользователь нажимает «Дополнить»,
   **Then** приложение показывает число записей «нужно дополнить» и команду для агента;
   агент заполняет только помеченные записи с пометкой происхождения ИИ.

### User Story 4 - Печатать ответ без французской клавиатуры (Priority: P4)

Пользователь включает переключатель «Ввод ответа». Вместо самооценки он печатает ответ.
Над полем — панель французских символов (é è ê ë à â ç œ ù û ü î ï ô). Если ответ набран
без спецсимволов и без них совпадает с правильным, приложение предлагает выбрать правильное
написание из вариантов; неверный выбор считается ошибкой.

**Why this priority**: тренирует написание и артикль, но базовое повторение работает
и без этого.

**Independent Test**: включить ввод → карточка RU → FR «лето» → набрать `ete` → выбрать `été`
из вариантов → ответ засчитан; в другой раз выбрать `ète` → ошибка.

**Acceptance Scenarios**:

1. **Given** включён ввод ответа, **When** пользователь нажимает символ на панели, **Then**
   символ вставляется в поле в позицию курсора.
2. **Given** правильный ответ `été`, **When** пользователь ввёл `ete`, **Then** показываются
   несколько вариантов написания, среди них правильный; выбор правильного засчитывается,
   неправильного — ошибка.
3. **Given** ответ введён полностью со спецсимволами, **When** он совпадает с правильным
   по правилам конституции (апостроф, регистр, пробелы не важны), **Then** он засчитан.
4. **Given** у записи несколько допустимых ответов (переводов), **When** пользователь вводит
   любой из них, **Then** ответ засчитан.
5. **Given** проверка завершена, **When** ответ неверен, **Then** показан правильный ответ,
   а оценка записывается как «Не помню».

### User Story 5 - Управлять записями (Priority: P5)

Пользователь правит любую запись (переводы, род, формы, заметки), удаляет свои записи,
скрывает записи из уроков. Лёгкие слова он отмечает «Я это знаю» — они исключаются
из повторения и собираются в отдельный список, откуда их можно вернуть.

**Why this priority**: поддержание словаря в порядке; нужно, когда словарь вырастет.

**Independent Test**: отметить слово «Я это знаю» → его нет в повторении → оно есть
в списке «Знаю» → вернуть → снова в повторении с прежней историей.

**Acceptance Scenarios**:

1. **Given** открыта карточка, **When** пользователь правит поля и заметки, **Then**
   изменения сохраняются, происхождение изменённых полей — «добавлено пользователем».
2. **Given** запись добавлена пользователем, **When** он её удаляет, **Then** запись
   удаляется после подтверждения; записи из уроков удалить нельзя, только скрыть.
3. **Given** запись отмечена «Я это знаю», **When** пользователь начинает повторение,
   **Then** запись не показывается; в списке «Знаю» она есть и её можно вернуть одним
   действием.
4. **Given** запись изменена, скрыта или возвращена, **When** пользователь смотрит её
   историю повторений, **Then** история сохранена.

---

### Edge Cases

- Направление RU → FR, а у перевода несколько французских записей (например, «красивый» —
  `beau` и `joli`): в режиме самооценки показывается подсказка (часть речи, пример);
  в режиме ввода засчитывается любая запись с этим переводом.
- Запись без перевода в нужном направлении не может появиться: перевод обязателен.
- Омонимы (`le livre` / `la livre`, `la pêche` — персик / рыбалка) — разные карточки
  (правила из функции 002, FR-021).
- Список для добавления содержит пустые строки, заголовки или комментарии — они
  игнорируются.
- В строке списка разделитель встречается несколько раз (фраза с тире внутри) — разбор
  по первому разделителю с пробелами; при сомнении строка показывается для исправления.
- Отмена оценки после завершения сеанса повторения — доступна только для последней оценки
  текущего сеанса.
- Слово пока не имеет форм / спряжения — дополнительный блок показывает «нужно дополнить».
- Озвучка недоступна в браузере — кнопка 🔊 сообщает об этом, остальное работает.
- Очень большой объём «пора повторить» после крупного урока — все карточки доступны,
  приложение показывает их количество до начала.
- Запись скрыта или в «Знаю», но входит в урок — в лексике урока (001) она по-прежнему
  видна, с пометкой.

## Requirements *(mandatory)*

### Functional Requirements

**Записи словаря**

- **FR-001**: Словарь ДОЛЖЕН содержать записи трёх видов: слово, глагол, фраза. Фраза —
  законченное высказывание («J'ai faim», «Ça va ?»); устойчивые выражения («avoir faim»)
  — слова или глаголы.
- **FR-002**: Запись ДОЛЖНА хранить: французский текст, один или несколько переводов,
  темы, уроки (необязательно), происхождение каждого поля. Слово дополнительно — определённый
  артикль, род, признаки «только множественное число», «оба рода», «h придыхательное», часть
  речи, женский род и множественное число с подсказкой образования. Неопределённый артикль
  не хранится, а выводится из рода и признаков (un / une / des) и показывается на карточке
  вместе с определённым. Глагол — группу,
  спряжение в настоящем времени для всех местоимений, признаки «возвратный» и «неправильный».
  Фраза — ситуацию употребления (необязательно).
- **FR-003**: Формат спряжения ДОЛЖЕН допускать добавление других времён без изменения
  существующих данных.
- **FR-004**: Запись ДОЛЖНА иметь заметки пользователя (например, исключения, произношение).
- **FR-005**: Правила «одно слово — одна запись» и накопления переводов — как в функции 002
  (FR-021, FR-021a).

**Просмотр**

- **FR-010**: Вкладка «Словарь» ДОЛЖНА показывать записи с фильтрами: все, урок, тема, вид
  (слова / глаголы / фразы), «Знаю», «Скрытые», «Нужно дополнить».
- **FR-011**: ДОЛЖНЫ быть два вида просмотра: карточки и быстрый список «слово — перевод».
- **FR-012**: Род ДОЛЖЕН показываться меткой (`m` / `f`) и цветом; у записей без рода —
  нейтральный цвет.
- **FR-013**: Дополнительный блок карточки ДОЛЖЕН быть свёрнут по умолчанию и содержать:
  формы слова, спряжение глагола, заметки, уроки, где запись встречалась, пример из урока.
- **FR-014**: Карточка ДОЛЖНА иметь кнопку произношения, использующую встроенный синтез речи
  браузера; при недоступности синтеза остальное работает.

**Добавление и дополнение**

- **FR-020**: Пользователь ДОЛЖЕН иметь возможность добавить запись вручную; обязательны
  французский текст и хотя бы один перевод.
- **FR-021**: Пользователь ДОЛЖЕН иметь возможность добавить записи списком. Строка: французский
  текст, разделитель (тире или дефис с пробелами), переводы через запятую. Необязательные
  пометки: артикль `le`/`la`/`l'`, `(m)`/`(f)`, `(v)`, `(adj)`, `(phr)`.
- **FR-022**: Нераспознанные строки ДОЛЖНЫ показываться для исправления, остальные —
  добавляться; пользователь ДОЛЖЕН видеть, какие строки объединены с существующими записями.
- **FR-023**: Записи с незаполненными полями (род, формы, спряжение, группа) ДОЛЖНЫ получать
  пометку «нужно дополнить»; их число ДОЛЖНО быть видно в словаре.
- **FR-024**: Кнопка «Дополнить» ДОЛЖНА показывать, сколько записей нужно дополнить,
  и команду для агента. Агент ДОЛЖЕН дополнять только помеченные записи, с пометкой
  происхождения ИИ, и снимать пометку; при сомнении — «требует проверки».

**Повторение**

- **FR-030**: Повторение ДОЛЖНО поддерживать режимы: «пора повторить сегодня», по уроку,
  по теме, все, «сложные»; фильтр вида: слова / глаголы / фразы / всё вместе.
- **FR-031**: Повторение ДОЛЖНО вестись в двух направлениях: FR → RU и RU → FR, с отдельным
  прогрессом и расписанием для каждого направления.
- **FR-032**: Порядок: показ вопроса → «Показать» → ответ → оценка «Не помню» / «С трудом» /
  «Помню». Оценка недоступна до показа ответа.
- **FR-032a**: Карточка проверяет только словарную (начальную) форму и перевод: для глагола —
  инфинитив, для существительного — форму с артиклем. Формы слова и спряжение в повторении
  словаря не спрашиваются (тренажёры форм — функция 004).
- **FR-033**: Кнопка «Отменить последнюю оценку» ДОЛЖНА возвращать последнюю карточку
  текущего сеанса и её прежнее состояние.
- **FR-034**: Расписание ДОЛЖНО строиться проверенным алгоритмом интервального повторения:
  чем лучше оценка, тем больше интервал до следующего показа. Оценки в любом режиме (урок,
  тема, все, сложные, «сегодня», ввод ответа) ДОЛЖНЫ обновлять расписание; алгоритм ДОЛЖЕН
  корректно учитывать повторение раньше срока.
- **FR-035**: Новые записи ДОЛЖНЫ автоматически попадать в «пора повторить сегодня» без
  ограничения количества; перед началом сеанса показывается число карточек.
- **FR-035a**: По умолчанию новая запись попадает в повторение только в направлении FR → RU;
  карточка RU → FR ДОЛЖНА создаваться, когда запись впервые оценена «Помню» в направлении
  FR → RU. В настройках ДОЛЖНА быть возможность выбрать другое поведение: «обе карточки
  сразу».
- **FR-035b**: Повторение, запущенное из урока («Повторить лексику урока»), ДОЛЖНО включать
  все слова урока одним сеансом. Повторение, запущенное из словаря, ДОЛЖНО идти порциями
  по N карточек (N задаётся в настройках); после порции — «Продолжить» или «Закончить».
- **FR-035c**: Сеанс ДОЛЖНО быть возможно закончить в любой момент; каждая оценка сохраняется
  сразу после выставления.
- **FR-036**: «Сложные» — записи, у которых среди последних оценок «Не помню» встречается
  чаще, чем «Помню».
- **FR-037**: Из урока (001) ДОЛЖНО быть доступно действие «Повторить лексику урока».

**Ввод ответа**

- **FR-040**: Режим ввода ответа ДОЛЖЕН включаться переключателем.
- **FR-041**: Над полем ввода ДОЛЖНА быть панель французских символов (é è ê ë à â ç œ ù û ü
  î ï ô); нажатие вставляет символ в позицию курсора.
- **FR-042**: Если ответ набран без спецсимволов и без их учёта совпадает с правильным,
  приложение ДОЛЖНО предложить выбрать правильное написание из нескольких вариантов;
  выбор неверного — ошибка.
- **FR-043**: Проверка введённого ответа ДОЛЖНА следовать конституции (принцип VIII):
  строго к буквам и диакритике, без учёта вида апострофа, регистра и лишних пробелов;
  засчитывается любой из допустимых ответов.
- **FR-044**: В режиме ввода верный ответ записывается как «Помню», неверный — как «Не помню»,
  правильный ответ показывается.

**Управление и данные**

- **FR-050**: Пользователь ДОЛЖЕН иметь возможность править любую запись; удалять — только
  свои записи (с подтверждением); записи из уроков — скрывать.
- **FR-051**: «Я это знаю» ДОЛЖНО исключать запись из повторения и помещать её в список
  «Знаю», откуда её можно вернуть одним действием.
- **FR-052**: Каждая оценка ДОЛЖНА сохраняться в истории повторений (дата, направление,
  оценка, режим); правка, скрытие, исключение и возврат записи НЕ ДОЛЖНЫ удалять историю.
- **FR-053**: Для данных прогресса (история и расписание повторений) ДОЛЖНО существовать
  резервное копирование и восстановление из копии. Копия ДОЛЖНА сохраняться в приватный
  репозиторий контента и отправляться в его удалённую копию на GitHub: автоматически раз
  в день (при первом запуске приложения за день) и вручную по кнопке.
- **FR-053a**: Если отправка копии не удалась (нет интернета), копия ДОЛЖНА сохраняться
  локально, отправка — повторяться при следующей возможности; приложение показывает дату
  последней успешной отправки. Работа приложения от этого не зависит.
- **FR-054**: Функция ДОЛЖНА работать без интернета (кроме озвучки, если браузеру она нужна)
  и быть удобной на экране телефона.

### Key Entities

- **Запись словаря**: вид (слово / глагол / фраза), французский текст, переводы (каждый —
  с уроком-источником и происхождением), темы, уроки, заметки, признаки «нужно дополнить»,
  «скрыто», «знаю», «требует проверки».
- **Слово** (вид записи): артикль, род, часть речи, формы (женский род, множественное число)
  с подсказкой образования.
- **Глагол** (вид записи): группа, признаки возвратный / неправильный, спряжение по временам
  (сейчас — настоящее).
- **Фраза** (вид записи): ситуация употребления.
- **Карточка повторения**: запись + направление; расписание (когда показать), состояние
  прогресса.
- **Оценка повторения**: карточка, дата, оценка, режим, способ (самооценка / ввод).
- **Резервная копия прогресса**: снимок истории и расписания повторений.
- **Настройки повторения**: порядок появления направлений для новых записей (по умолчанию —
  сначала FR → RU); размер порции N при повторении из словаря.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: В «пора повторить сегодня» попадают 100% карточек, срок которых наступил,
  и ни одной, срок которой не наступил (кроме новых).
- **SC-002**: Прогресс в направлениях FR → RU и RU → FR независим: оценка в одном направлении
  не меняет расписание другого.
- **SC-002a**: Слово, повторённое с оценкой «Помню» через урок, не появляется в «Пора
  повторить сегодня» на следующий день как новое или просроченное.
- **SC-003**: Список из 50 строк в мягком формате добавляется без ручной правки не менее чем
  для 95% строк.
- **SC-004**: Любое французское слово с диакритикой можно правильно ответить в режиме ввода
  без французской раскладки клавиатуры.
- **SC-005**: После правки, скрытия, исключения и возврата записи её история повторений
  сохраняется полностью.
- **SC-006**: Данные прогресса восстанавливаются из резервной копии без потерь.
- **SC-007**: Все экраны функции пригодны для работы на экране шириной 375 пикселей без
  горизонтальной прокрутки.

## Assumptions

- Слова уроков приходят из функции 002; эта функция их показывает, повторяет и позволяет
  править.
- В режиме FR → RU вопрос — французская запись (с артиклем), ответ — переводы; в RU → FR —
  наоборот.
- «Сложные» определяются по последним 5 оценкам записи в любом направлении.
- Удаление своей записи удаляет и её карточки, но история оценок остаётся в резервных копиях.
- Выбор конкретного алгоритма интервального повторения — решение этапа плана.
