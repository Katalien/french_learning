# Research: Словарь и карточки

## R1. Где хранить прогресс

- **Decision**: SQLite-файл `CONTENT_DIR/.progress/progress.sqlite` (папка в `.gitignore`
  хранилища). Резервная копия — текстовый SQL-дамп `backups/progress.sql` в хранилище,
  коммит + отправка на GitHub раз в день (первый запрос к приложению за день) и по кнопке.
  Версии копии — это история git этого файла.
- **Rationale**: конституция (стек: SQLite для прогресса; VI: приватно, с копией; VII: история
  не удаляется); текстовый дамп даёт читаемые git-диффы и восстановление без сторонних
  программ; один файл вместо сотни датированных копий.
- **Alternatives**: коммитить сам `.sqlite` (бинарный, шумная история); копии в облачную
  папку (отклонено в clarify 003).

## R2. Алгоритм интервального повторения

- **Decision**: FSRS (Free Spaced Repetition Scheduler), библиотека `fsrs` (Python, MIT).
  Оценки: «Не помню» → Again, «С трудом» → Hard, «Помню» → Good (Easy не используется).
  Каждое направление — отдельная карточка (FR-031).
- **Rationale**: современный алгоритм (используется в Anki), корректно учитывает повторение
  раньше срока (FR-034, clarify 003 — оценки в любом режиме меняют расписание); готовая
  проверенная реализация вместо самописной (VIII — «проверенный алгоритм»).
- **Alternatives**: SM-2 (проще, но плохо учитывает досрочные повторы); самописный FSRS
  (риск ошибок).

## R3. Карточки и направления

- **Decision**: карточка = (запись словаря, направление). FR → RU создаётся для каждой
  нескрытой записи при первой синхронизации; RU → FR — после первой оценки «Помню» в FR → RU
  (настройка `directions = staged`, по умолчанию) или сразу (`both`). «Я это знаю» —
  карточки записи приостановлены (`suspended`), возврат снимает флаг; история не трогается.
- **Rationale**: clarify 003 (Q2); прогресс направлений независим (SC-002).

## R4. Что спрашивается и что считается ответом

- **Decision**: FR → RU: вопрос — французский с артиклем у существительных («la maison»),
  ответ — все переводы. RU → FR: вопрос — переводы + подсказка (часть речи, пример), ответ —
  французский с артиклем. В режиме ввода: для RU → FR у существительных **артикль обязателен**
  (тренирует род), засчитывается любая запись с этим переводом (spec, Edge Cases);
  для FR → RU засчитывается любой перевод, без учёта регистра, «ё» = «е».
- **Rationale**: FR-032a (начальная форма, существительное с артиклем); принцип VIII.

## R5. Проверка введённого ответа (общая с функцией 004)

- **Decision**: модуль `practice/checking.py`: нормализация «клавиатурных» различий
  (апострофы ' ’ ʼ, регистр, лишние и неразрывные пробелы, пробел перед ? ! ; :, конечная
  точка) и строгое сравнение букв и диакритики. Если ответ совпадает с правильным без учёта
  диакритики — результат «нужен выбор написания»: варианты = правильный + до 3 правдоподобных
  подмен акцентов на тех же буквах (e ↔ é è ê ë, a ↔ à â, u ↔ ù û ü, i ↔ î ï, o ↔ ô, c ↔ ç,
  oe ↔ œ), перемешанные.
- **Rationale**: FR-041–FR-044, решение пользователя про клавиатуру; тот же модуль нужен
  упражнениям 004 (FR-004, FR-010–FR-011 спецификации 004).

## R6. Разбор списка слов (FR-021, FR-022)

- **Decision**: чистая функция `parse_word_list(text)` → распознанные строки и
  нераспознанные. Разделитель — первое « — », « – » или « - » (с пробелами) либо табуляция;
  переводы через запятую / точку с запятой; артикль le / la / l' / les в начале; пометки
  `(m)` `(f)` `(v)` `(adj)` `(phr)` и др.; строки с `?` `!` или из нескольких слов без
  артикля — фраза; пустые строки и строки с `#` — пропускаются. Всё неуказанное →
  `needs_completion: true`.
- **Rationale**: мягкий формат из обсуждения; разбор без ИИ (IX), тестируемо (XIII).

## R7. Добавление и правка слов — в файлы контента

- **Decision**: новые слова, правки, заметки, скрытие — через `ContentWriter` (атомарная
  запись, коммит, отправка), как правки 001. Новое поле формата `hidden: bool` у лексики
  (необязательное, формат v1). Объединение со существующими — правила 002 (форма + часть
  речи + род; переводы накапливаются).
- **Rationale**: слова — контент, единый источник правды — файлы (001 R2); агент видит правки.

## R8. Дополнение слов агентом (FR-024)

- **Decision**: навык `/complete-words`: находит записи `needs_completion: true`, заполняет
  род / артикль / формы / группу и спряжение глагола в настоящем времени с `origin: ai`
  для заполненных полей (поле `completed_by_ai` со списком полей), снимает пометку; через
  черновик и `commit-staging`. В приложении — кнопка «Дополнить» с числом записей
  и командой.
- **Rationale**: ИИ только по запросу (X), приложение без ИИ (IX).

## R9. Сеанс повторения

- **Decision**: сеанс хранится в SQLite (`sessions`): параметры (режим, вид, направление,
  урок / тема, способ ответа), очередь id карточек, позиция, последняя оценка для отмены.
  Из урока — все карточки урока одной очередью; из словаря — порции по N (настройка,
  по умолчанию 20). Каждая оценка пишется сразу (FR-035c). «Отменить» восстанавливает
  состояние карточки из снимка, сохранённого вместе с оценкой, и удаляет эту оценку
  из истории (единственное допустимое удаление — отмена ошибочного нажатия в том же сеансе).
- **Rationale**: FR-033, FR-035b; история остаётся полной для реальных оценок.

## R10. «Сложные» (FR-036)

- **Decision**: запись сложная, если среди её последних 5 оценок (оба направления)
  «Не помню» больше, чем «Помню».

## R11. Озвучка (FR-014)

- **Decision**: Web Speech API браузера (`speechSynthesis`, голос `fr-FR`), кнопка 🔊;
  нет голоса / API — кнопка сообщает, остальное работает. Никаких внешних сервисов.

## R12. Интерфейс

- **Decision**: вкладка «Словарь» в меню; страницы: список (фильтры, вид «карточки / список»),
  карточка записи (род — цвет и метка m / f, доп. блок свёрнут), добавление (одно слово /
  список), повторение (настройка сеанса → карточка → «Показать» → оценки; ввод — поле,
  панель символов, выбор написания), «Знаю», «Скрытые», «Нужно дополнить», настройки,
  резервная копия. Кнопка «Повторить лексику урока» на странице теории урока. Вёрстка —
  в стиле 001 (редизайн — отдельно, веха 4).

## R13. Параметры FSRS

- **Decision**: `Scheduler(learning_steps=(), relearning_steps=())` — без внутридневных шагов:
  интервалы в днях (новое слово: «Не помню» / «С трудом» → завтра, «Помню» → через 2 дня).
  Перемешивание интервалов (fuzzing) включено в работе и выключено в тестах. Слово с оценкой
  «Не помню» в текущем сеансе повторно не показывается — оно придёт завтра.
- **Rationale**: при шагах по умолчанию (1 и 10 минут) слово, оценённое «Помню» через урок,
  назавтра оказалось бы просроченным — нарушение SC-002a; ежедневное повторение
  естественнее для словаря.
