# Data Model: 012

Схема базы прогресса и формат контента **не меняются**.

## Слово словаря (контент, `vocabulary/*.yaml`)

- `hidden: true` — как раньше; теперь скрытое слово исключено из лексики урока, тем, списка
  тем и всех счётчиков. Видно только в словаре с фильтром «скрытые» и на своей странице.
- Удаление — файл слова удаляется из хранилища контента (коммит «Словарь: удалено «…»»),
  для любого слова (раньше — только своего без уроков).

## Прогресс удалённого слова (база прогресса)

- Карточки FSRS и история оценок остаются (принцип VII). Слово не существует в контенте —
  карточки не попадают ни в повторение, ни в счётчики.

## Вопрос тренажёра «Числа»

| Ключ | Карточка | Ответ | Подсказка |
|---|---|---|---|
| `numbers:N` (как раньше) | `N` цифрами | все написания словами | «напишите словами» |
| `numbers-fr:N` (новое) | основное написание словами | `N` цифрами | «напишите цифрами» |

Параметры сеанса тренажёра: к `scope`, `low`, `high` добавляется `format`
(`digits_to_words` по умолчанию | `words_to_digits`).

## Звук озвучки (кеш `~/.french-learning/tts/cache`)
