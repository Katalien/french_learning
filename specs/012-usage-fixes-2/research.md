# Research: 012 — Правки после использования, второй список

## R1. «Задания 6/10»

- **Decision**: `_counts` в `web/routes/lessons.py` отдаёт `tasks_class` и `tasks_homework`
  (без резерва, как сейчас общий счётчик); в панели — «Задания 6/10», `title="в классе: 6,
  дома: 10"`. Домашние — все (обязательные и дополнительные).
- **Rationale**: общий счётчик уже считается так же; сумма двух чисел = прежнее число.
- **Alternatives**: «6 + 10» — пользователь просил именно «6/10».

## R2. Раскладка после «Проверить» (воспроизведено на демо, 1400 px)

- **Причина**: блок `#exercise-solve` заменяется ответом сервера (`hx-swap="outerHTML"`).
  Класс `with-source` (два столбца) ставит Alpine через `:class` по состоянию «картинка
  открыта». HTMX при замене элемента с тем же `id` на этапе settle возвращает новому элементу
  атрибуты из ответа сервера — `class="exercise solve"` — уже после того, как Alpine поставил
  класс. Состояние `picture` не меняется, поэтому Alpine класс не возвращает: картинка
  открыта, а сетка одна колонка → картинка сверху, задание под ней. До проверки:
  `exercise solve with-source`, 550 px + 550 px; после: `exercise solve`, одна колонка.
- **Decision**: оставить `id` и `x-data` на внешнем блоке, а сетку и `:class` перенести на
  внутреннюю обёртку без `id` (`.exercise-layout`), которую HTMX не трогает на этапе settle;
  селекторы CSS `.exercise.with-source …` → `.exercise-layout.with-source …`. Проверить
  остальные места с `id` + `:class` + `outerHTML` (карточка повторения, тренажёры) и исправить
  так же, если найдутся.
- **Alternatives**: класс на сервере — сервер не знает, открыл ли пользователь картинку
  (состояние в браузере); `htmx.config` без settle — затронет всё приложение.

## R3. Обрезанное начало озвучки

- **Наблюдение**: в готовых звуках Piper речь начинается через 0,08–0,19 с от начала файла.
  Звуковое устройство (особенно Bluetooth-наушники и энергосбережение звука в Windows)
  «просыпается» при начале воспроизведения 0,2–0,5 с и съедает начало; при быстрых повторных
  нажатиях устройство уже активно — звучит целиком. Это совпадает с описанием («со 2–3 раза
  нормально»).
- **Decision**: (1) добавлять в начало каждого звука 0,35 с тишины при синтезе; ключ кеша
  получает версию (`pad1`), старые файлы просто перестают использоваться (кеш пересоздаётся
  при первом нажатии); (2) в `speech.js` при повторном нажатии — `pause()`, `currentTime = 0`,
  `play()`, чтобы слово всегда начиналось заново.
- **Rationale**: тишина в файле не зависит от браузера и устройства; задержка 0,35 с почти
  незаметна.
- **Alternatives**: постоянно «будить» звук тихим потоком Web Audio — лишняя нагрузка,
  ненадёжно; предзагрузка — не помогает, дело не в сети. Проверка — на слух пользователем при
  приёмке (агент звук не слышит); вопрос пользователю: наушники Bluetooth? — для подтверждения.

## R4. Скрытые слова и удаление

- **Сейчас**: словарь без фильтра скрытые уже прячет; лексика урока (`lesson_vocabulary`),
  страница темы и `partials/vocab_list.html` показывают их с пометкой «скрыто». Удаление
  (`VocabEditor.delete`) разрешено только своим словам без уроков.
- **Decision**: `lesson_vocabulary` и слова темы — без скрытых (вместе с этим верны счётчики
  «Лексика», вкладки темы, связанные фильтры 011, соседи для стрелок); пометка «скрыто»
  остаётся только на странице самого слова и в фильтре «скрытые». `delete` — для любых слов;
  кнопка «Удалить слово» на странице слова открывает `<dialog>` подтверждения с самим словом;
  POST `/vocab/{id}/delete` → словарь с сообщением «Слово удалено». Карточки FSRS и оценки
  остаются в базе (VII); повторение берёт только существующие слова, так что они не видны.
- **Edge**: незаконченный сеанс со словом, которое удалили, — карточка пропускается (проверить
  тестом, что сеанс не падает).

## R8. Правило оформления теории

- **Decision**: дописать в `.claude/skills/_shared/content-rules.md` раздел про теорию:

## R9. «Числа»: словами → цифрами

- **Decision**: генератор отдаёт и вторые вопросы `numbers-fr:N` (prompt — основное написание
  `spellings(n)[0]`, ответ — `str(n)`, подсказка «напишите цифрами»). На странице настройки —
  выбор формата (радио «цифрами → словами» по умолчанию / «словами → цифрами»); параметр
  сеанса `format` фильтрует вопросы по префиксу; `in_range` понимает оба префикса. Расписание
  FSRS и ошибки — по ключу вопроса, то есть у форматов раздельно. Проверка ответа — общая
  (`checking.py`): пробелы по краям не ошибка.
- **Будущее**: формат на слух (озвучка → цифры) — «Веха 4».
