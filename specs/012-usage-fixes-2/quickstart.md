# Quickstart: проверка 012

Демо: `uv run python -m french_learning.cli serve --port 8010 --content-dir <демо>`
(конфигурация `french-learning-demo` в `.claude/launch.json`). Тесты: `uv run pytest`.

1. **Задания 6/10** — урок 1 демо → панель: «Задания К/Д», сумма равна прежнему числу,
   подсказка при наведении.
2. **Раскладка** — ширина 1400 px, упражнение из фото (`/elements/ex-gapinput`), открыть
   картинку → заполнить → «Проверить»: у блока остаётся класс `with-source`, два столбца,
   координаты задания и картинки те же; то же после «Сбросить»; при ширине 375 px порядок
   блоков не меняется.
3. **Озвучка** — `/tts?text=maison`: первые 0,35 с — тишина (тест); при приёмке
   пользователь слушает 10 разных слов по одному нажатию.
4. **Скрытые / удаление** — скрыть слово урока → его нет в лексике урока, на странице темы,
   в счётчике «Лексика»; есть в словаре с фильтром «скрытые». «Удалить слово» у слова урока →
   окно → «Отмена» — ничего; «Удалить» → словарь, «Слово удалено.», слова нет нигде; в базе
   прогресса его карточки остались.
5. **Клавиши** — страница слова: ↓ раскрывает «Подробнее», ↑ сворачивает, ↑ ещё раз —
   ничего, Enter — звук; в поле правки слова клавиши работают как обычно.
6. **Темы** — тема раздела «Лексика» без слов не видна на `/topics`, открывается по адресу.
7. **Главная** — «N слов урока L» (последний урок со словами) → «Повторить» → сеанс
   ru→fr из N карточек.
8. **Числа** — настройка: формат «словами → цифрами», диапазон 70–99 → карточка словами,
   ввести цифры → верно; неверно → показан ответ; основной формат работает как раньше.
9. **Правило агента** — раздел о теории в `.claude/skills/_shared/content-rules.md`.
