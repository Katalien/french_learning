# Contract: команды для навыков тренажёров

Как в 002: `uv run french-learning <команда>`, JSON в stdout, коды выхода 0 / 1 / 2.
Пакеты заданий сохраняются через существующие `stage-check` и `commit-staging`
(`.staging/<op>/trainers/<id>/tb-*.yaml`); идентификаторы — `new-ids tb`.

| Команда | Что делает | Вывод |
|---|---|---|
| `trainers-list` | Каталог: id, название, источник, тип упражнения, правила, сколько заданий в пуле | JSON `[…]` |
| `trainer-context <id>` | Всё для генерации: правила тренажёра, слова словаря (текст, артикль, род, переводы), темы пройденных уроков, уже существующие задания (против повторов) | JSON |
| `mistakes-list [--trainer <id>] [--lesson N]` | Ошибки: для тренажёра — задания из «Ошибок» с ответами пользователя; для уроков — пункты «Моих ошибок» с ответами и правильными ответами | JSON |

## Навыки (`.claude/skills/`)

- `/generate-tasks <тренажёр> [сколько, по умолчанию одна порция]`: `trainer-context` →
  пакет по правилам (≤ 2 новых слов на пункт, с переводом; сомнительное —
  `needs_review`) → `stage-check` → `commit-staging`. Тренажёра нет в каталоге —
  предложить `/add-trainer`.
- `/add-trainer <описание>`: подходящий `exercise_type` из поддерживаемых → запись
  в `trainers.yaml` (через черновик). Нужен новый тип — сообщить о доработке приложения,
  запись не добавлять.
- `/explain-mistakes [тренажёр | урок N]`: `mistakes-list` → объяснение ошибок с опорой
  на теорию уроков.
