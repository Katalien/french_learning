# Contract: страницы и действия упражнений и тренажёров

## Упражнения уроков

| Адрес | Что | Требования |
|---|---|---|
| `GET /elements/{ex-id}` | Упражнение как форма: поля по типу, справка скрыта, панель символов; последняя попытка с результатом или черновик; «Решить заново», «История» | FR-001, FR-007, FR-010, FR-021 |
| `POST /exercises/{id}/draft` | Автосохранение черновика (ответы) | FR-006 |
| `POST /exercises/{id}/check` | Проверка всех пунктов → фрагмент упражнения с подсветкой, выбором написания, «Показать ответ», «Не согласна» | FR-002–FR-004, FR-011, FR-020, FR-020a |
| `POST /exercises/{id}/reveal/{item}` | Показать правильный ответ пункта (отметка «подсмотрен») | FR-003, FR-020a |
| `POST /exercises/{id}/save` | Открытый ответ: сохранить без проверки | FR-005 |
| `POST /exercises/{id}/restart` | Новая пустая попытка | FR-021 |
| `GET /exercises/{id}/history` | Все попытки: дата, ответы, итог, «пересчитано» | FR-021, FR-031 |
| `POST /exercises/{id}/status` | Основное / необязательное / резерв → счётчики урока пересчитаны | FR-032 |
| `POST /exercises/{id}/items/{item}/report` | «Не согласна с ответом» → сообщение + напоминание; происхождение ответа видно всегда | FR-030 |
| `GET /mistakes?lesson=&topic=` | «Мои ошибки»: пункты с итогом «ошибка» | FR-021a |
| `GET /mistakes/{ex-id}/{item}` · `POST …/check` | Прорешать один пункт (попытка `scope=item`) | FR-021a |

Счётчик домашки «X из Y» на страницах урока — из `ExerciseProgress` (FR-022).

## Тренажёры

| Адрес | Что | Требования |
|---|---|---|
| `GET /trainers` | Каталог: встроенные и с генерацией; у каждого — описание, источник, «пора сегодня» / «в пуле N» | FR-040, FR-060 |
| `GET /trainers/{id}` | Запуск: набор данных (весь словарь, урок, тема, сложные); для пакетов — сколько в пуле, «Ошибки», статистика; «не хватает данных» / «пул пуст» с командой агента | FR-041a, FR-046, FR-050b, FR-052 |
| `POST /trainers/{id}/start` | Сеанс → первое задание порции | FR-045a |
| `GET /trainers/s/{session}` | Текущее задание: кнопки, поле ввода с панелью символов или сборка предложения; подсказки новых слов | FR-042, FR-050a |
| `POST /trainers/s/{session}/answer` | Проверка → результат (или выбор написания) → «Дальше» | FR-011, FR-044, FR-051 |
| `POST /trainers/s/{session}/spelling` | Выбор написания | FR-011 |
| `POST /trainers/s/{session}/reveal` | Показать ответ (= ошибка) | FR-020a |
| `POST /trainers/s/{session}/continue` | Следующая порция после итога | FR-045a |
| `GET /trainers/{id}/mistakes` | «Ошибки» тренажёра с пакетами | FR-051 |
| `GET /trainers/{id}/stats` | Процент верных, динамика по дням, типичные ошибки | FR-053 |
| `POST /trainers/tasks/{tb-id}/{item}/report` | «Не согласна» у задания пакета | Edge Cases |
| `GET /settings` · `POST /settings` | + размер порции тренажёров | FR-045a |
