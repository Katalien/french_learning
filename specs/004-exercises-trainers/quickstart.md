# Quickstart: проверка функции 004

## Подготовка

```bash
uv sync
uv run pytest
uv run french-learning serve
```

Хранилище — настоящее (`CONTENT_DIR`), уроки 13 и 14. Для автоматических тестов —
синтетический образец `tests/fixtures/content` (все типы упражнений).

## Сценарии приёмки

1. **Упражнение (US1)**: урок 14 → «Задания» → «Домашка» → упражнение с выбором
   из списка → заполнить → «Проверить» → ошибки подсвечены → исправить одну, у другой
   «Показать ответ» → «Проверить» → на сводке урока счётчик домашки +1.
2. **Клавиатура (FR-004, FR-011)**: в поле ввода набрать ответ с `’` и заглавной буквой —
   засчитано; набрать `ete` вместо `été` — предложен выбор написания.
3. **Черновик (FR-006)**: ввести часть ответов, уйти со страницы, вернуться — ответы на месте.
4. **История (US2)**: «Решить заново» → решить без ошибок → «История» — две попытки.
5. **Мои ошибки (FR-021a)**: `/mistakes?lesson=14` — пункты с ошибками; прорешать один
   верно — он ушёл из списка.
6. **Не согласна и статус (US3)**: «Не согласна» у пункта → сообщение в списке сообщений;
   перевести упражнение в «необязательное» → счётчик пересчитан.
7. **Встроенные тренажёры (US4)**: «Тренажёры» → «Артикли» → урок 14 → ответить; одну
   ошибку сделать намеренно → в следующей порции этот вопрос раньше. «Числа» → `97` →
   `quatre-vingt-dix-sept`. «Спряжение» без глаголов в словаре — подсказка
   про `/complete-words`.
8. **Задания от агента (US5)**: в Claude Code — `/generate-tasks negation 5` (после
   `/add-trainer` для «Отрицания», US6) → решить: 4 верно, 1 неверно → в пуле 1,
   в «Ошибках» 1, статистика 80% → решить оставшееся → «пул пуст» с командой.
9. **Разбор ошибок**: `/explain-mistakes negation` — объяснение в чате.
10. **Телефон (SC-008)**: страницы упражнения и тренажёра на ширине 375 px без
    горизонтальной прокрутки.
11. **Замер качества (SC-005 из 002)**: по ходу сценариев 1–6 на уроках 13 и 14 —
    `uv run french-learning quality-sample --lesson 13 --lesson 14`, сверка; итог — доля
    ошибок ≤ 5%, записать в CHANGELOG.

Ожидаемый результат по каждому шагу — в acceptance scenarios [spec.md](spec.md).
