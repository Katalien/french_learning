# Feature Specification: Упражнения с автопроверкой и тренажёры

**Feature Branch**: `004-exercises-trainers`

**Created**: 2026-09-27

**Status**: Draft

**Input**: Описание пользователя (собрано из обсуждения): «Я открываю урок, иду в домашку
и выполняю упражнение прямо в интерфейсе: выбираю из списка или печатаю. Нажимаю
„Проверить“ — вижу, где ошиблась, могу исправить или посмотреть ответ. Упражнение можно
перерешать, все попытки сохраняются. Если не согласна с ответом — сообщаю. Отдельно есть
тренажёры: спряжение, артикли (через подстановку артикля к слову), женский род, множественное
число и другие — из моего словаря. А есть тренажёры, для которых агент по моей просьбе
генерирует порцию заданий с ответами; я решаю их в приложении.» Подробности —
`docs/roadmap.md`, функция 004.

## Границы функции

- **Входит**: выполнение и автопроверка упражнений уроков; история попыток; перерешивание;
  «не согласна с ответом»; смена статуса упражнения; счётчик выполненной домашки; общий
  механизм ввода ответа (панель символов, выбор написания); встроенные тренажёры из словаря
  и материалов уроков с интервальным повторением; тренажёры с пулом заданий от агента
  и статистикой; каталог тренажёров; навык агента для генерации заданий.
- **Не входит**: проверка открытых ответов через LLM (веха 4), статистика прогресса по урокам
  и темам в целом (008), аудирование (веха 4), спряжение в других временах кроме настоящего
  (формат допускает, реализация позже).

## Clarifications

### Session 2026-09-27

- Q: Встроенные тренажёры берут слова из всего словаря или можно выбрать урок / тему? → A:
  Выбор перед запуском: весь словарь (по умолчанию), урок, тема, «сложные».
- Q: Как засчитывать пункт, если пользователь подсмотрел ответ или исправил ошибку? → A: Итог
  пункта — по первой проверке («верно сразу» / «ошибка») плюс отметка «исправлено
  самостоятельно» или «подсмотрен ответ»; в статистике «подсмотрен ответ» считается ошибкой.
- Q: Нужен ли список «Ошибки» для упражнений уроков? → A: Да — общий список «Мои ошибки»
  по упражнениям уроков с фильтром по уроку и теме; отдельные пункты можно прорешать;
  пункт уходит из списка, когда решён верно.
- Q: Какую лексику и грамматику агент может использовать в сгенерированных заданиях? → A:
  В основном слова из словаря и грамматику пройденных уроков; новые слова допустимы —
  не больше 2 на пункт (предложение), каждое с переводом-подсказкой.
- Q: Сколько заданий показывать за один подход в тренажёрах? → A: Порциями по N (отдельная
  настройка для тренажёров, по умолчанию 20); после порции — итог и «Продолжить» /
  «Закончить»; остановиться можно в любой момент. Пул сгенерированных заданий может
  содержать сразу несколько порций про запас.

## User Scenarios & Testing *(mandatory)*

### User Story 1 - Выполнить упражнение и проверить себя (Priority: P1)

Пользователь открывает упражнение урока (например, домашку урока 14) и заполняет ответы
в интерфейсе: выпадающие списки, поля ввода, выбор варианта, верно / неверно, распределение
по группам. Нажимает «Проверить»: ошибки подсвечиваются, верные — отмечены. Он исправляет
ошибки и проверяет снова или открывает правильный ответ по кнопке «Показать ответ».

**Why this priority**: ради этого проект и задумывался — интерактивные упражнения вместо
картинок.

**Independent Test**: открыть упражнение «Complétez avec du, de la, de l', des» (урок 14) →
выбрать артикли → «Проверить» → увидеть подсветку ошибок → исправить → «Проверить» → всё
верно; счётчик домашки урока увеличился.

**Acceptance Scenarios**:

1. **Given** упражнение типа «пропуск с выбором из списка», **When** оно открыто, **Then**
   каждый пропуск — выпадающий список из вариантов упражнения.
2. **Given** пользователь заполнил ответы, **When** он нажимает «Проверить», **Then** каждый
   пункт отмечен верным или неверным; до нажатия проверка не выполняется.
3. **Given** после проверки есть ошибки, **When** пользователь исправляет ответ и снова
   нажимает «Проверить», **Then** проверяются исправленные ответы; правильный ответ
   к пункту можно открыть кнопкой «Показать ответ».
4. **Given** правильный ответ к пропуску — `de l'`, **When** пользователь ввёл `de l’`
   (типографский апостроф) или `De l'`, **Then** ответ засчитан (конституция, принцип VIII).
5. **Given** правильный ответ — `été`, **When** пользователь ввёл `ete`, **Then** ему
   предлагается выбрать правильное написание из вариантов; неверный выбор — ошибка.
6. **Given** у пропуска несколько допустимых ответов, **When** пользователь ввёл любой
   из них, **Then** ответ засчитан.
7. **Given** упражнение домашки проверено целиком хотя бы раз, **When** пользователь смотрит
   сводку урока, **Then** счётчик «X из Y» учитывает его как выполненное, независимо
   от результата.
8. **Given** у упражнения есть справка, **When** пользователь выполняет его, **Then** справка
   скрыта и открывается по кнопке как подсказка.
9. **Given** пункт 2 был неверен и пользователь исправил его сам, а к пункту 5 открыл
   «Показать ответ», **When** попытка сохраняется, **Then** пункт 2 — «ошибка, исправлено
   самостоятельно», пункт 5 — «ошибка, подсмотрен ответ»; в статистике пункт 5 считается
   ошибкой.

### User Story 2 - Перерешать упражнение и видеть историю (Priority: P2)

Пользователь начинает упражнение заново с чистого листа. Все прошлые попытки сохранены;
по умолчанию видна последняя, историю можно открыть.

**Why this priority**: повторение — основа обучения; история нужна для прогресса
и будущего репетитора.

**Independent Test**: решить упражнение с 2 ошибками → «Решить заново» → решить без ошибок
→ в истории две попытки с датами и результатами.

**Acceptance Scenarios**:

1. **Given** упражнение уже решалось, **When** пользователь открывает его, **Then** видна
   последняя попытка с результатом; доступно действие «Решить заново».
2. **Given** пользователь выбрал «Решить заново», **When** упражнение открывается, **Then**
   поля пусты, а прошлые попытки сохранены в истории.
3. **Given** у упражнения несколько попыток, **When** пользователь открывает историю,
   **Then** видны все попытки с датой, ответами и результатом.
4. **Given** в упражнениях уроков 13 и 14 есть пункты с ошибками, **When** пользователь
   открывает «Мои ошибки» с фильтром «урок 14», **Then** видны только пункты урока 14;
   пункт, решённый верно, уходит из списка.

### User Story 3 - Не согласиться с ответом и управлять статусом (Priority: P3)

Пользователь считает, что правильный ответ неверен, и нажимает «Не согласна с ответом»
у пункта — создаётся сообщение об ошибке (функция 001). Пользователь меняет статус
упражнения: основное / необязательное / резерв.

**Why this priority**: защита от ошибок агента и управление составом урока.

**Independent Test**: нажать «Не согласна» у пункта 3 → сообщение создано и видно в списке
сообщений; перевести упражнение в «необязательное» → счётчик домашки пересчитан.

**Acceptance Scenarios**:

1. **Given** пункт проверен, **When** пользователь нажимает «Не согласна с ответом»
   и пишет комментарий, **Then** создаётся сообщение об ошибке, привязанное к пункту,
   и показывается напоминание о разборе сообщений агентом (001, FR-043); происхождение
   правильного ответа показывается независимо от переключателя происхождения.
2. **Given** агент исправил правильный ответ по сообщению, **When** пользователь смотрит
   историю, **Then** прошлые попытки сохранены как были, а их результат пересчитан
   по исправленному ответу с пометкой «пересчитано».
3. **Given** упражнение основное, **When** пользователь меняет статус на «необязательное»
   или «резерв», **Then** упражнение перемещается в соответствующий список, а счётчик
   домашки пересчитывается.

### User Story 4 - Тренироваться на встроенных тренажёрах (Priority: P2)

Пользователь открывает вкладку «Тренажёры» и выбирает встроенный тренажёр: спряжение
(настоящее время), артикли (определённый и неопределённый), женский род, множественное
число, притяжательные, указательные, согласование прилагательного, числа, «собери
предложение». Задания строятся приложением из словаря (слова только из словаря) и материалов
уроков, без агента. Тренажёр чаще спрашивает то, в чём пользователь ошибается.

**Why this priority**: регулярная тренировка форм без затрат токенов.

**Independent Test**: в словаре 10 существительных и 3 глагола → тренажёр «Артикли» задаёт
вопросы по этим словам в определённой и неопределённой форме → ошибка в `___ eau`
(неопределённый) → этот вопрос появляется снова раньше других.

**Acceptance Scenarios**:

1. **Given** тренажёр «Артикли», **When** показано слово `___ maison`, **Then** требуется
   подставить артикль (кнопками или вводом); спрашиваются определённая и неопределённая
   формы; перевод слова не спрашивается.
2. **Given** слово на гласную `eau`, **When** спрашивается определённая форма, **Then** верный
   ответ — `l'`; прогресс засчитывается по «элизии»; для неопределённой формы (`une`) —
   по «роду».
3. **Given** слово с h придыхательным `héros`, **When** спрашивается определённая форма,
   **Then** верный ответ — `le`, а `l'` — ошибка.
4. **Given** тренажёр «Спряжение», **When** показано `parler — nous`, **Then** требуется
   ввести `parlons`; проверка — по правилам конституции (принцип VIII).
5. **Given** тренажёр «Притяжательные», **When** показано `___ amie` (моя), **Then** верный
   ответ — `mon`.
6. **Given** тренажёр «Числа», **When** показано `97`, **Then** верный ответ —
   `quatre-vingt-dix-sept`.
7. **Given** тренажёр «Собери предложение», **When** показаны перемешанные слова
   правильного предложения из упражнений уроков, **Then** пользователь расставляет их
   по порядку, и приложение проверяет порядок.
8. **Given** в словаре нет данных для тренажёра (например, нет глаголов со спряжением),
   **When** пользователь его открывает, **Then** приложение сообщает, каких данных не хватает
   и как их получить (например, «дополнить слова» агентом).
9. **Given** пользователь ответил в тренажёре, **When** ответ оценён, **Then** расписание
   вопроса обновляется интервальным алгоритмом, а ответ сохраняется в истории.
10. **Given** пользователь запускает тренажёр «Артикли», **When** он выбирает «урок 14»,
    **Then** вопросы строятся только по словам лексики урока 14; по умолчанию выбран весь
    словарь.

### User Story 5 - Решать задания, сгенерированные агентом (Priority: P3)

Пользователь просит агента в чате: «сгенерируй 15 заданий для тренажёра „Отрицание“».
Агент создаёт пул заданий с правильными ответами. Пользователь решает их во вкладке
тренажёра. Верно решённые задания уходят в архив, неверно решённые остаются в пуле
и попадают в список «Ошибки». Когда пул пуст, приложение подсказывает попросить новую
порцию. По тренажёру видна статистика.

**Why this priority**: гибкая практика на любую тему, но требует агента и токенов.

**Independent Test**: попросить агента сгенерировать 5 заданий «Артикли в контексте» →
решить в приложении: 4 верно, 1 неверно → в пуле осталось 1 задание, в «Ошибках» — 1,
статистика 80% → решить оставшееся верно → пул пуст, сообщение с командой для агента.

**Acceptance Scenarios**:

1. **Given** пользователь попросил агента сгенерировать задания для тренажёра из каталога,
   **When** агент их создал, **Then** в пуле тренажёра появились задания с правильными
   ответами (происхождение «создано ИИ», сомнительные — «требует проверки»), по правилам
   тренажёра из каталога.
2. **Given** задание решено верно, **When** проверка завершена, **Then** оно уходит из пула
   в архив, попытка сохраняется.
3. **Given** задание решено неверно, **When** проверка завершена, **Then** оно остаётся
   в пуле и добавляется в список «Ошибки» тренажёра.
4. **Given** пул пуст, **When** пользователь открывает тренажёр, **Then** приложение
   сообщает, что заданий нет, и показывает команду для агента.
5. **Given** тренажёр решался несколько раз, **When** пользователь открывает статистику,
   **Then** видны процент верных ответов, динамика во времени и типичные ошибки.
6. **Given** пользователь просит агента «разбери мои ошибки в тренажёре X», **When** агент
   читает список «Ошибки» и попытки, **Then** он объясняет ошибки в чате.
7. **Given** агент сгенерировал задания, **When** пользователь их решает, **Then** в каждом
   пункте не больше 2 слов, которых нет в словаре, и у каждого такого слова видна
   подсказка-перевод.

### User Story 6 - Добавить свой тренажёр (Priority: P4)

Пользователь описывает агенту идею нового тренажёра. Агент добавляет запись в каталог:
название, описание, источник заданий (агент), правила генерации, тип упражнения. Тренажёр
появляется во вкладке «Тренажёры».

**Why this priority**: расширяемость; нужна после того, как основные тренажёры работают.

**Independent Test**: попросить агента создать тренажёр «Вопросы с est-ce que» → он появился
в каталоге и во вкладке → попросить сгенерировать задания → решить их.

**Acceptance Scenarios**:

1. **Given** идея тренажёра укладывается в существующие типы упражнений, **When** агент
   добавляет его в каталог, **Then** тренажёр доступен без изменения кода приложения.
2. **Given** идее нужен новый тип упражнения, **When** агент её разбирает, **Then** он
   сообщает, что потребуется доработка приложения, и не добавляет неработающий тренажёр.
3. **Given** встроенный тренажёр, **When** в каталоге его источник заданий переключают
   на «агент», **Then** задания берутся из пула, сгенерированного агентом.

### Edge Cases

- Упражнение типа «открытый ответ»: ответ сохраняется, автопроверки нет; упражнение
  считается выполненным после сохранения ответа; показывается пояснение, что проверка
  появится позже.
- Упражнение «по картинке»: исходный файл показывается рядом (001).
- Пользователь закрыл упражнение, не нажав «Проверить»: введённые ответы сохраняются как
  черновик, попытка не засчитывается.
- Пункт упражнения помечен «требует проверки» (агент не уверен в ответе): при проверке
  пользователь видит эту пометку рядом с результатом пункта.
- Трансформация предложения: пробел перед `?` / `!`, завершающая точка, регистр первой
  буквы, вид апострофа не влияют на проверку.
- «Собери предложение»: если в предложении допустимы разные порядки слов, засчитываются
  все допустимые (из ответов упражнения); при их отсутствии — только исходный порядок.
- Слова с обоими родами (`élève`): в тренажёре артиклей верны оба артикля.
- Слова только во множественном числе (`les gens`): неопределённый артикль — `des`.
- В пуле тренажёра задание, помеченное «требует проверки», решено «неверно»: пользователь
  может нажать «Не согласна» — задание уходит в сообщения об ошибках.
- Агент сгенерировал задания для тренажёра, которого нет в каталоге: задания не сохраняются,
  агент предлагает сначала добавить тренажёр.

## Requirements *(mandatory)*

### Functional Requirements

**Выполнение и проверка упражнений**

- **FR-001**: Каждый тип упражнения (001, FR-020) ДОЛЖЕН выполняться в интерфейсе: выпадающий
  список, поле ввода, несколько полей в строке, ввод предложения, верно / неверно, выбор
  варианта, выбор из двух форм, распределение по группам, «по картинке», открытый ответ.
- **FR-002**: Проверка ДОЛЖНА выполняться для всего упражнения по кнопке «Проверить»; каждый
  пункт отмечается верным или неверным.
- **FR-003**: После проверки пользователь ДОЛЖЕН иметь возможность исправить неверные ответы
  и проверить снова; правильный ответ пункта ДОЛЖЕН открываться кнопкой «Показать ответ».
- **FR-004**: Проверка ДОЛЖНА следовать конституции (принцип VIII): строго к буквам,
  диакритике и дефисам; без учёта вида апострофа, регистра, лишних пробелов, пробела перед
  `?`/`!` и завершающей точки; засчитывается любой из допустимых ответов.
- **FR-005**: Упражнения «открытый ответ» ДОЛЖНЫ сохранять ответ без автопроверки.
- **FR-006**: Незавершённые ответы ДОЛЖНЫ сохраняться как черновик до проверки.
- **FR-007**: Справка к упражнению ДОЛЖНА быть скрыта и открываться по кнопке-подсказке.

**Ввод ответа (общий механизм с функцией 003)**

- **FR-010**: Над полями ввода ДОЛЖНА быть панель французских символов (é è ê ë à â ç œ ù û ü
  î ï ô); нажатие вставляет символ в позицию курсора.
- **FR-011**: Если ответ набран без спецсимволов и без их учёта совпадает с правильным,
  приложение ДОЛЖНО предложить выбрать правильное написание из нескольких вариантов;
  неверный выбор — ошибка.

**Попытки и история**

- **FR-020**: Каждая проверка ДОЛЖНА сохраняться как попытка: дата, ответы, результат
  по пунктам (конституция, принцип VII).
- **FR-020a**: Итог пункта в попытке ДОЛЖЕН определяться по первой проверке: «верно сразу»
  или «ошибка». Для пунктов с ошибкой ДОЛЖНА сохраняться отметка: «исправлено
  самостоятельно» (исправлен после подсветки без показа ответа) или «подсмотрен ответ»
  (исправлен после «Показать ответ»). В статистике и прогрессе «подсмотрен ответ» считается
  ошибкой; «исправлено самостоятельно» учитывается отдельно от «верно сразу».
- **FR-021**: Пользователь ДОЛЖЕН иметь возможность решить упражнение заново с пустыми
  полями; по умолчанию показывается последняя попытка, история доступна.
- **FR-021a**: ДОЛЖЕН быть общий список «Мои ошибки»: пункты упражнений уроков, итог
  которых в последней попытке — «ошибка», с фильтром по уроку и теме. Пункты из списка можно
  прорешать по отдельности; пункт уходит из списка, когда решён верно; решение сохраняется
  как попытка.
- **FR-022**: Упражнение ДОЛЖНО считаться выполненным после первой полной проверки,
  независимо от результата (для счётчика домашки 001, FR-031).

**Ошибки в ответах и статусы**

- **FR-030**: У каждого проверенного пункта ДОЛЖНО быть действие «Не согласна с ответом»,
  создающее сообщение об ошибке (001, FR-042) с напоминанием (001, FR-043); происхождение
  правильного ответа в этот момент показывается всегда.
- **FR-031**: После исправления правильного ответа агентом прошлые попытки ДОЛЖНЫ сохраняться
  без изменений ответов, а их результат — пересчитываться по исправленному ответу с пометкой
  «пересчитано».
- **FR-032**: Пользователь ДОЛЖЕН иметь возможность менять статус упражнения (основное /
  необязательное / резерв); счётчики урока пересчитываются.

**Встроенные тренажёры**

- **FR-040**: Вкладка «Тренажёры» ДОЛЖНА содержать встроенные тренажёры: спряжение
  (настоящее время), артикли, женский род, множественное число, притяжательные (mon / ma /
  mes и др.), указательные (ce / cet / cette / ces), согласование прилагательного, числа,
  «собери предложение».
- **FR-041**: Встроенные тренажёры ДОЛЖНЫ строить задания без агента: из словаря (003) —
  только из слов словаря; «собери предложение» — из правильных предложений упражнений
  и текстов уроков; «числа» — по правилам записи чисел.
- **FR-041a**: Перед запуском встроенного тренажёра пользователь ДОЛЖЕН выбирать набор
  данных: весь словарь (по умолчанию), урок, тема или «сложные» (вопросы тренажёра, в которых
  пользователь часто ошибается).
- **FR-042**: Тренажёр «Артикли» ДОЛЖЕН спрашивать определённую и неопределённую формы
  у всех слов, ответ — подстановкой артикля (кнопками или вводом); перевод не спрашивается.
  Неопределённый артикль выводится из рода и признаков слова (003).
- **FR-043**: Правила артиклей ДОЛЖНЫ учитывать: элизию `l'` перед гласной и h немым;
  h придыхательное (без элизии); слова обоих родов (верны оба артикля); слова только
  во множественном числе (`les` / `des`).
- **FR-044**: Прогресс встроенных тренажёров ДОЛЖЕН вестись интервальным повторением
  для каждого вопроса; в тренажёре артиклей — отдельно для определённой (элизия) и
  неопределённой (род) формы.
- **FR-045**: Тренажёр «Спряжение» ДОЛЖЕН спрашивать одну форму глагола для местоимения;
  формат ДОЛЖЕН допускать добавление других времён.
- **FR-045a**: Подход к любому тренажёру (встроенному и с генерацией) ДОЛЖЕН идти порциями
  по N заданий; N — отдельная настройка для тренажёров (по умолчанию 20). После порции
  показывается итог (например, «18 из 20») и выбор «Продолжить» / «Закончить».
  Остановиться можно в любой момент; ответы сохраняются сразу.
- **FR-046**: Если в словаре не хватает данных для тренажёра, приложение ДОЛЖНО сообщать,
  каких, и как их получить.

**Тренажёры с генерацией агентом**

- **FR-050**: Для тренажёров с источником «агент» по запросу пользователя в чате агент ДОЛЖЕН
  генерировать пул заданий с правильными ответами (все допустимые варианты), происхождением
  «создано ИИ» и пометкой «требует проверки» при сомнениях, по правилам тренажёра
  из каталога.
- **FR-050a**: В сгенерированных заданиях агент ДОЛЖЕН использовать в основном слова
  из словаря и грамматику пройденных уроков. Новые слова допустимы — не больше 2 на пункт
  (предложение); каждое новое слово ДОЛЖНО сопровождаться переводом-подсказкой, видимой
  при выполнении задания.
- **FR-050b**: Пул ДОЛЖЕН вмещать несколько порций; пользователь может попросить агента
  сгенерировать сразу несколько порций про запас (например, «3 порции по 20»). Приложение
  показывает, сколько заданий осталось в пуле.
- **FR-051**: Верно решённое задание ДОЛЖНО уходить из пула в архив; неверно решённое —
  оставаться в пуле и добавляться в список «Ошибки» тренажёра; попытки сохраняются всегда.
- **FR-052**: При пустом пуле приложение ДОЛЖНО сообщать об этом и показывать команду
  для агента.
- **FR-053**: Для тренажёров с генерацией ДОЛЖНА вестись статистика: процент верных ответов,
  динамика во времени, типичные ошибки; интервальное повторение для них не ведётся.
- **FR-054**: По просьбе «разбери мои ошибки в тренажёре X» агент ДОЛЖЕН читать список
  «Ошибки» и попытки и объяснять ошибки.
- **FR-055**: Генерация выполняется только по явному запросу пользователя (конституция,
  принцип X).

**Каталог тренажёров**

- **FR-060**: Каталог ДОЛЖЕН описывать каждый тренажёр: название, описание, источник заданий
  (встроенный / агент), правила для агента, тип упражнения, способ учёта прогресса
  (интервальное повторение / статистика).
- **FR-061**: Агент ДОЛЖЕН уметь добавлять тренажёр в каталог по описанию пользователя; если
  нужен тип упражнения, которого нет, — сообщать о необходимости доработки приложения.
- **FR-062**: Источник заданий встроенного тренажёра ДОЛЖНО быть возможно переключить
  на «агент».

**Общие**

- **FR-070**: Функция ДОЛЖНА работать без интернета (кроме генерации заданий агентом)
  и быть удобной на экране телефона.

### Key Entities

- **Попытка**: упражнение или задание тренажёра, дата, ответы по пунктам, итог по пунктам
  (верно сразу / ошибка + исправлено самостоятельно / подсмотрен ответ), признаки
  «черновик», «пересчитано».
- **Тренажёр** (запись каталога): название, описание, источник заданий, правила для агента,
  тип упражнения, способ учёта прогресса.
- **Вопрос встроенного тренажёра**: тренажёр + элемент данных (слово, форма, число,
  предложение) + вариант (например, определённая / неопределённая форма); расписание.
- **Пул заданий**: задания тренажёра, сгенерированные агентом, ещё не решённые верно.
- **Архив заданий**: верно решённые задания с попытками.
- **Список «Ошибки»**: задания пула, решённые неверно.
- **Список «Мои ошибки»**: пункты упражнений уроков с итогом «ошибка» в последней попытке.
- **Статистика тренажёра**: процент верных, динамика, типичные ошибки.
- Упражнение, сообщение об ошибке, запись словаря — как в функциях 001–003.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 100% упражнений поддерживаемых типов (кроме «открытого ответа») выполняются
  и проверяются в интерфейсе без обращения к оригиналу.
- **SC-002**: Проверка соответствует правилам конституции: на наборе контрольных примеров
  (апостроф, регистр, пробелы, диакритика, несколько ответов) 100% случаев оцениваются верно.
- **SC-003**: Любой ответ с французскими символами можно ввести без французской раскладки.
- **SC-004**: 100% проверок сохраняются в истории; после «Решить заново» и после исправления
  ответа агентом прошлые попытки не теряются.
- **SC-005**: Тренажёр «Артикли» даёт верную оценку для 100% контрольных слов, включая
  элизию, h придыхательное, оба рода и только множественное число.
- **SC-006**: Вопрос, на который пользователь ответил неверно, во встроенном тренажёре
  появляется снова раньше, чем вопрос, на который он ответил верно.
- **SC-007**: Новый тренажёр на существующих типах упражнений добавляется агентом без
  изменения кода приложения.
- **SC-008**: Все экраны функции пригодны для работы на экране шириной 375 пикселей без
  горизонтальной прокрутки.

## Assumptions

- Упражнения и правильные ответы приходят из функции 002; эта функция их выполняет
  и проверяет.
- Черновик ответов хранится до проверки или «Решить заново» и не считается попыткой.
- Для «собери предложение» используются предложения, полный правильный вид которых известен
  (пункты упражнений с заполненными ответами, предложения текстов).
- Тренажёр «Числа» использует числа от 0 до 1000; диапазон можно расширить.
- Сгенерированные задания решаются в интерфейсе приложения, а не в чате.
- Встроенные тренажёры с интервальным повторением используют тот же алгоритм, что карточки
  словаря (003).
- Каталог тренажёров хранится в приватном хранилище вместе с контентом.
