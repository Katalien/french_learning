# UI routes: 011

| Адрес | Изменение |
|---|---|
| `GET /practice/setup` | в поле «Тема» — только темы со словами |
| `GET /practice/{id}` | ru_fr + существительное с родом → кнопка `rating=article` «Ошибка в артикле»; переводы — по строке, классы `tr-m` / `tr-s` |
| `POST /practice/{id}/rate` | принимает `rating=article` (только там, где кнопка показана; иначе 404) |
| `POST /practice/{id}/drill` | новый: `which=again` или `again_hard` → 303 на новый сеанс-тренировку; нет слов — 303 обратно на итог |
| итог сеанса (`GET /practice/{id}` в конце) | строка «Ошибка в артикле: N»; кнопки «Повторить „Не помню“ (N)» и «Повторить „Не помню“ и „С трудом“ (M)», если N / M > 0; у тренировки — пометка «Тренировка — без записи» |
| `GET /lessons/{n}/vocab?topic=&kind=` | фильтры «Тема» (темы слов урока) и «Вид»; ссылки на слова `?from=lesson&lesson=n&topic=&kind=` |
| `GET /vocab/{id}?from=lesson&lesson=n&topic=&kind=` | стрелки, ← / →, «N из M» — по отфильтрованному списку урока; «назад» — к лексике с фильтром |
| `GET /trainers/articles/…` | вопросы слов с приоритетом — первыми в порции |
