# Quickstart: проверка 011 (демо, порт 8010)

1. **Темы**: «Практика» → «Настроить» → «По теме» — в списке нет тем без слов.
2. **Ошибка в роде**: «Все слова», «русский → французский» → на существительном четвёртая
   кнопка «Ошибка в роде»; у глагола / фразы — нет; в «французский → русский» — нет.
   Нажать → итог: строка «Ошибка в роде: 1». Открыть тренажёр «Артикли» → первым идёт
   это слово. «Отменить последнюю оценку» до тренажёра → приоритет снят.
3. **Переводы**: слово с 3 длинными переводами (добавить вручную в демо) → обе стороны,
   режим ввода — текст внутри карточки на 1280 и 375 px.
4. **Тренировка**: сеанс 5 слов, 2 «Не помню», 1 «С трудом» → итог: «Повторить „Не помню“ (2)»,
   «… и „С трудом“ (3)» → нажать → 2 карточки, пометка «Тренировка — без записи» → история
   слов не изменилась.
5. **Фильтры лексики урока**: урок → «Лексика» → «Тема» / «Вид» → список сузился → открыть
   слово → стрелки и ← / → по отфильтрованным словам; «назад» — с тем же фильтром.

Перед проверкой: `uv run pytest`, `uv run ruff check .`, `uv run ruff format .`.
