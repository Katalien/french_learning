# Research: Повторение и лексика урока (011)

## R1. Темы со словами в настройке повторения (пункт 1)

- **Decision**: `topic_options` в `practice_setup` строятся только из тем, у которых есть хотя
  бы одно нескрытое слово (`vocab_entries` → множество `topics`). Неизвестная или пустая тема
  в адресе — не выбрана (комбобокс пуст), счётчик 0.
- **Alternatives**: показывать все темы с пометкой «нет слов» — лишний шум.

## R2. «Ошибка в артикле» (пункт 2)

- **Decision**:
  - Новая оценка `article` в `RATINGS` (`vocab/cards.py`) → FSRS `Good` («как Помню»). В
    `reviews.rating` пишется `article` — отдельный вид ответа для истории и итога.
  - `hard_ids` («сложные») считает `article` как нейтральную — не `again` и не `good`.
  - Кнопка — только `direction == "ru_fr"` и существительное с родом (`articles.has_gender`,
    `is_noun` из генератора тренажёра — тот же критерий, что у вопросов тренажёра).
  - Приоритет в тренажёре: новая таблица `trainer_priority (trainer_id, key, review_id,
    created_at)` (схема v5). При оценке `article` — строки для `articles:<id>:def` и
    `articles:<id>:indef` со ссылкой на оценку. `TrainerSchedule.select` ставит такие ключи
    первыми (по времени добавления). Ответ на вопрос в тренажёре снимает приоритет этого ключа.
  - Отмена оценки (`undo`) удаляет строки приоритета этой оценки.
- **Rationale**: «в начало очереди» без подделки расписания FSRS тренажёра; отмена точная.
- **Alternatives**: сдвинуть `due` карточки тренажёра в прошлое — портит расписание и
  сложно отменить; оценка `again` в тренажёре — неверная статистика ответов.

## R3. Переводы на карточке (пункт 3)

- **Decision**: `Question` получает `lines` (список переводов) для ru_fr; ответы `answers` —
  уже список. Шаблоны выводят каждый перевод отдельной строкой (`<span class="tr-line">`).
  Класс размера по общему числу символов: `tr-m` (> 40), `tr-s` (> 80) — меньший шрифт.
  `overflow-wrap: anywhere` — длинное слово переносится. На лицевой и обратной стороне,
  в режиме ввода и на странице результата ответа.
- **Alternatives**: подгонка шрифта скриптом по фактической высоте — сложнее; классов по
  длине достаточно (карточка 320 px, с прокруткой внутри стороны как запас).

## R4. Повтор-тренировка (пункт 5)

- **Decision**:
  - На итоге обычного сеанса: слова, у которых **последняя** оценка в этом сеансе `again`
    (кнопка 1) или `again`/`hard` (кнопка 2), — запрос по `reviews.session_id`.
  - `POST /practice/{id}/drill` с `which=again|again_hard` создаёт новый сеанс с
    `params.drill = True`, теми же направлением, способом, видом; очередь — эти карточки,
    перемешана; порция — все.
  - В сеансе-тренировке `SessionStore.rate` не вызывает `CardStore.rate`: оценки пишутся
    только в состояние сеанса (`state["drill"]`), `undo` снимает последнюю оттуда, `summary`
    считает оттуда. Расписание, `reviews`, «сложные» — без изменений.
  - Итог тренировки показывает свои кнопки повтора (по её собственным ответам) и пометку
    «Тренировка — без записи».
- **Alternatives**: отдельная клиентская мини-игра без сервера — дублирование карточки.

## R5. Фильтры лексики урока (пункт 4)

- **Decision**: `GET /lessons/{n}/vocab?topic=&kind=` — фильтрация списков «Новые» / «На
  повторение» на сервере; формы-фильтры — выпадающие списки, как в словаре (смена → GET).
  Темы в фильтре — только темы слов этого урока. Ссылки на слово —
  `?from=lesson&lesson=n&topic=&kind=`; `_source_list` применяет те же фильтры; ссылка
  «назад» — `/lessons/n/vocab?topic=&kind=`.
