# Дорожная карта French Learning

Документ уровня проекта: какие функции будут в приложении, в каком порядке и что от чего
зависит. Детальные требования — в спецификациях `specs/NNN-*/spec.md`, правила проекта —
в [конституции](../.specify/memory/constitution.md).

## Цель проекта

Превратить разрозненные файлы уроков французского (фото, PDF, документы) в единую систему:
**база знаний + словарь с карточками + тренажёр упражнений**. Наполняет систему агент
Claude Code, а приложение показывает материал и работает без ИИ.

## Вехи

| Веха | Функции | Результат |
|---|---|---|
| **1. База знаний** | 001, 002 | Уроки добавляются агентом, их можно читать |
| **2. Тренажёр** ⭐ первая рабочая версия | 003, 004 | Словарь с карточками, упражнения с автопроверкой |
| **3. Удобства** | 005–008 | Заметки, чтение с переводом, поиск, статистика |
| **4. Позже** | — | Идеи без детального планирования (см. ниже) |

## Порядок и зависимости

```text
001 Формат ─┬─► 002 /add-lesson ─┬─► 003 Словарь ────┬─► 006 Чтение с переводом
            │                    │                   ├─► 007 Поиск
            │                    │                   └─► 008 Статистика
            │                    └─► 004 Упражнения ────► 008 Статистика
            └─► 005 Заметки ────────────────────────────► 007 Поиск
```

### 001 — Формат, хранилище и просмотр уроков ✅

**Зависит от:** —

**Входит:**
- формат хранения контента (уроки, теория, лексика, тексты, упражнения) — договор между
  агентом и приложением;
- приватное хранилище контента, отдельное от публичного репозитория кода;
- просмотр урока: вкладки «классная работа» / «домашняя работа» с переключением на
  группировку по видам (теория, лексика, тексты, упражнения);
- просмотр по теме через все уроки;
- переключатель отображения происхождения (материалы / ИИ / внешний ресурс / вручную);
- просмотр оригинала для сверки;
- пометки «требует проверки» со значком, раскрывающим пояснение агента, и кнопка «сообщить
  об ошибке» в контенте с напоминанием, что сообщения разбирает агент;
- инфраструктура проекта (первая функция с кодом): тесты, линтер и форматтер, git-хуки и CI,
  `README.md`, `CHANGELOG.md`, раздел «Команды» в `CLAUDE.md`, исключение секретов из git.

**Не входит:** добавление контента агентом (→ 002), выполнение упражнений (→ 004) — здесь
упражнения только отображаются.

**Пожелания для спецификации:**
- главный экран: список всех уроков (новые сверху) со сводкой у каждого + вход в темы;
- темы — сгруппированным списком (грамматика / лексика / произношение и т. п.);
- сводка урока: номер (из имени папки `Leçon NN`), дата (агент берёт из файлов, пользователь
  подтверждает), темы, число новых слов, сколько заданий домашки выполнено;
- внутри урока: «Теория», «Тексты» и «Задания»; задания — две вкладки «В классе» / «Домашка»;
  текст — самостоятельный элемент, не часть теории;
- название упражнения: «номер — тема — короткое описание на русском»;
- урок ≠ тема: в уроке бывают упражнения на повторение прошлых тем, тема задаётся каждому
  элементу;
- теория отображается текстом, с возможностью открыть оригинальный документ;
- аудио и видео не отображаются: в уроке показывается список таких файлов, пользователь
  открывает их сам.

### 002 — Навык агента `/add-lesson` ✅

**Зависит от:** 001

**Входит:**
- обработка материалов урока (фото, PDF, документы) в формат 001;
- выбор, какие задания добавить и с каким статусом (основное / необязательное / резерв);
- разделение на классную и домашнюю работу;
- перевод формулировок заданий на русский с сохранением оригинала;
- решение упражнений с пометкой «решено ИИ»;
- самопроверка и отчёт: добавлено / пропущено / требует проверки;
- сжатие копий оригиналов;
- добавление материала по ссылке из интернета.

**Пожелания для спецификации:**
- типы упражнений составить по реальным фото материалов;
- один файл может содержать несколько элементов (несколько упражнений; теорию и упражнения;
  текст и упражнения к нему) — агент разделяет их;
- теория берётся из файлов теории; справки на листах упражнений не становятся отдельной
  теорией, а прикрепляются к упражнению. Исключение: если справка содержит тему, которой нет
  в теории урока (например, таблица указательных местоимений на уроке про артикли), она
  добавляется как теория;
- признаки файла теории: объяснения занимают большую часть файла, файл в папке урока (не
  `Devoirs`), название — тема, текст преподавателя; признаки листа со справкой: основная часть
  — пронумерованные задания, объяснение короткое (таблица сверху/сбоку), готовый лист из
  интернета. В отчёте агент пишет, как классифицировал каждый файл; пользователь может
  поправить;
- упражнения по картинке: рядом с упражнением показывается исходный файл (вариант 1).
  Альтернатива на случай проблем: агент превращает смысл картинки в текст (например,
  «un stylo ✗, une gomme ✓»);
- метки и ответы на фото (редкие исключения) игнорируются — упражнение считается
  невыполненным;
- дубли файлов (один файл в классе и в домашке) не страшны; по умолчанию — домашка;
- аудио и видео не обрабатываются, только фиксируются в уроке.

### 003 — Словарь и карточки 📝

**Зависит от:** 001, 002

**Входит:**
- словарь всех слов из уроков и добавленных вручную: без дублей, с грамматикой (род,
  артикль, словарная форма) и ссылками на уроки, где слово встречалось;
- ручное добавление слова и списка слов в приложении;
- карточки с интервальным повторением по проверенному алгоритму;
- история повторений;
- резервное копирование данных прогресса (здесь появляются первые такие данные).

**Пожелания для спецификации:**
- отдельная вкладка «Словарь»: просмотр всех записей, по урокам, по темам, по видам;
- три вида записей: слово, глагол, фраза (законченное высказывание: «J'ai faim», «Ça va ?»);
  устойчивые выражения («avoir faim») — слова. Повторение общее для всех видов, данные разные;
- добавление своих записей по одной и списком. Формат списка мягкий: обязательно только
  «французское — перевод» (несколько переводов через запятую); подробный вариант (артикль,
  род `(m)/(f)`, `(v)`, `(adj)`, `(phr)`) тоже поддерживается. Недостающие поля (род, формы,
  спряжение) помечаются «нужно дополнить» и заполняются агентом по кнопке/команде
  с пометкой ИИ;
- карточка слова: артикль, слово, род (метка m/f + цвет; нейтральный цвет для слов без
  рода), часть речи, переводы. Дополнительный блок (свёрнут): женский род и множественное
  число с подсказкой образования, для глаголов — группа и спряжение в настоящем времени
  (формат допускает другие времена в будущем), уроки, где встречалось, пример из урока,
  заметки пользователя (исключения, произношение);
- режимы повторения: «пора повторить сегодня» (алгоритм), по уроку, по теме, все, «сложные»;
  фильтр: только слова / только фразы / только глаголы / всё вместе;
- два направления: французский → русский и русский → французский, прогресс по каждому
  направлению отдельно;
- порядок: вспомнить → «Показать» → оценить себя: «Не помню» / «С трудом» / «Помню»;
  кнопка «Отменить последнюю оценку»;
- режим ввода ответа (включается переключателем): панель французских символов над полем;
  если ответ набран без спецсимволов и совпадает без них — выбор правильного написания
  из вариантов, неверный выбор = ошибка;
- новые слова попадают в повторение автоматически, без ограничения в день;
- «я это знаю» — исключить из повторения; такие слова в отдельном списке, можно вернуть;
- кнопка 🔊 произношения на карточке (встроенный синтез речи браузера);
- правка любой записи; удаление — только своих; слова из уроков можно скрыть;
- в карточках вспоминается только начальная форма и перевод; формы и спряжение — справка
  в доп. блоке (тренажёры форм — в 004). Идея на потом: отдельный «словарь глаголов»
  (пока его заменяет фильтр «только глаголы»);
- из урока — кнопка «повторить лексику урока»: режим карточек или список «слово — перевод»
  для быстрого просмотра;
- слова урока извлекаются агентом из файлов лексики урока и уже есть в словаре; слово новое,
  если его не было в лексике прошлых уроков (встречи в упражнениях не считаются);
- ручное добавление слов к теме, без обязательной привязки к уроку;
- одно слово — одна запись: слово определяется словарной формой + частью речи + родом;
  одинаковое написание с разным смыслом — разные записи; сомнения — «требует проверки»;
- у слова может быть несколько переводов (в том числе при ручном добавлении); переводы
  из разных уроков накапливаются, а не затираются;
- на карточке источник слова (уроки, где встречалось) не показывается постоянно —
  по отдельной кнопке;
- карточки слов разного рода — разного цвета (продумать: оба рода `un/une élève`, род
  меняет смысл `le/la livre`, слова без рода).

### 004 — Упражнения с автопроверкой и тренажёры 📝

**Зависит от:** 001, 002

**Входит:**
- **выполнение упражнений в интерфейсе и автоматическая проверка ответов** — ядро функции;
- интерактив по типам (выпадающие списки, ввод текста и т. д.);
- проверка по правилам конституции (принцип VIII);
- сохранение каждой попытки, история выполнения;
- «я не согласна с ответом»;
- смена статуса упражнения в приложении;
- прогресс по уроку (выполнение основных упражнений);
- генерация упражнений агентом по запросу (навык агента: «сделай 10 упражнений на артикли»).

**Не входит:** автоматическая проверка открытых ответов (нужна LLM) → веха 4.

**Пожелания для спецификации:**
- сценарий: открыть урок → «Домашка» → выполнить упражнение в интерфейсе → зафиксировать
  ответ → сразу увидеть, что верно, а что нет (проверяет приложение, без ИИ);
- черновой список типов (по материалам уроков 13–14): пропуск с выбором из списка, пропуск
  со свободным вводом, несколько пропусков в предложении, трансформация предложения,
  верно/неверно, выбор варианта, выбор из двух форм, распределение по группам, по картинке,
  открытый ответ; аудирование — не поддерживается;
- справка к упражнению скрыта по умолчанию: сначала пользователь пробует сам, потом может
  открыть справку как подсказку;
- проверка — всего упражнения по кнопке «Проверить»; ошибки подсвечиваются, их можно
  исправить; правильный ответ — по кнопке «Показать ответ»;
- «выполнено» (для счётчика домашки) — упражнение хотя бы раз проверено целиком, независимо
  от результата;
- упражнение можно перерешать с чистого листа; все попытки сохраняются, видна последняя;
- отдельный блок «Тренажёры» (данные — из словаря 003):
  - спряжение: сейчас настоящее время; формат и тренажёр допускают другие времена и формы;
  - артикль: проверяется знание рода через подстановку артикля к слову (не кнопки «м/ж»);
    перевод при этом не спрашивается;
  - женский род (образование формы) и множественное число — отдельные тренажёры;
  - встроенные тренажёры без агента (из словаря и материалов уроков): притяжательные
    (mon/ma/mes), указательные (ce/cet/cette/ces), согласование прилагательного, числа,
    «собери предложение»; источник заданий можно позже переключить на агента;
  - слова в тренажёрах — только из словаря;
  - прогресс (интервальное повторение) пока ведётся по всем тренажёрам; позже решим,
    где он не нужен;
- каталог тренажёров: название, описание, источник заданий (встроенный / агент), правила
  для агента, тип упражнения. Пользователь может придумывать новые тренажёры — агент
  добавляет запись в каталог; код меняется, только если нужен новый тип упражнения;
- тренажёры с генерацией агентом (артикли в контексте, отрицание и др.): по просьбе в чате
  агент генерирует пул заданий с правильными ответами; приложение показывает и проверяет;
  верно решённые задания уходят из пула в архив (попытки сохраняются); неверно решённые
  остаются в пуле и попадают в список «Ошибки»; пустой пул — сообщение «попросите агента
  сгенерировать новую порцию»;
- прогресс: у встроенных тренажёров — интервальное повторение; у сгенерированных —
  статистика (процент верных, динамика, типичные ошибки);
- артикли в тренажёре: определённый и неопределённый у всех слов (кнопками и вводом);
  прогресс отдельно по форме (определённый — элизия / h придыхательное, неопределённый —
  род); неопределённый артикль выводится из рода, не хранится;
- ввод ответов — тот же механизм, что в карточках (003): панель французских символов
  и выбор правильного написания, если ответ набран без спецсимволов;
- провести отложенный из 002 замер качества агента (SC-005: ≤ 5% ошибок распознавания
  и ответов на уроках 13 и 14) — `quality-sample`, заодно по ходу выполнения упражнений;
- в трансформациях допустимы несколько правильных вариантов; пробел перед `?` и `!` —
  «клавиатурная» разница.

## Веха 4 — позже

- Редизайн интерфейса (отдельная функция через Spec Kit, с макетами до кода): текущий вид
  пользователю не нравится; решено сначала доделать смысловую часть 001–004, затем заняться
  дизайном и расположением кнопок. Логика и данные от оформления отделены — меняются только
  шаблоны и стили.
  Замечания пользователя после приёмки 001:
  - страница темы: не одним общим списком, а по категориям (теория, тексты, упражнения,
    слова) с переключением вкладками;
  - страница урока: кнопки «Теория / Тексты / Задания» дублируются (панель разделов
    и карточки разделов) — оставить одно;
  - общий вид и расположение кнопок пользователю не нравятся.

- Доступ с телефона: развёртывание, защищённый канал, возможно Docker.
- Агент-репетитор: разбор ошибок с опорой на материалы уроков; предупреждает, если ответ
  не из материалов.
- Подготовка переводов текстов агентом при добавлении урока (вместо внешнего сервиса) —
  отложено ради экономии токенов.
- Проверка открытых ответов через LLM по API.
- Аудио и видео в приложении: проигрывание прямо в уроке и в упражнениях на аудирование.
- Картинка на карточке слова (идея на подумать): пользователь сам изображения искать
  не будет. Варианты для обсуждения: картинки из материалов урока, если слово там
  проиллюстрировано; подбор агентом из открытых фотобанков; генерация изображения.
  Учесть: авторские права, расход токенов, место в хранилище.
