## 0.11.0 — на приёмке

### 012 — Правки после использования, второй список (2026-10-07)

Спецификация — `specs/012-usage-fixes-2/`.

- **«Задания 6/10»** в панели разделов урока: в классе / дома (резерв не считается), подсказка
  при наведении.
- **Раскладка упражнения с картинкой** не меняется после «Проверить»: задание слева, картинка
  справа. Причина: при замене блока упражнения HTMX возвращал ему классы из ответа сервера
  и стирал раскладку «в два столбца»; теперь она на внутренней обёртке.
- **Озвучка без обрезанного начала**: в начале каждого звука 0,35 с тишины (наушники и звук
  Windows «просыпаются» и съедали начало слова); повторное нажатие — слово заново с начала.
  Кеш звука пересоздаётся сам при первом нажатии.
- **Скрытые слова** больше не показываются в лексике урока, на страницах тем и в счётчиках —
  только в словаре с фильтром «скрытые» (там же «Вернуть»).
- **«Удалить слово»** на странице любого слова (и из урока): окно подтверждения, слово
  удаляется из словаря полностью; история повторений остаётся в базе (принцип VII), но нигде
  не видна. Незаконченный сеанс повторения пропускает удалённое слово.
- **Клавиши на странице слова**: ↓ — раскрыть «Подробнее», ↑ — свернуть, Enter — прослушать.
- **Темы → Лексика**: только темы, где есть слова (тема открывается по прямой ссылке).
- **Главная, «Повторение слов»**: число слов последнего урока со словами; «Повторить» — сразу
  сеанс со всеми словами этого урока, «русский → французский».
- **Тренажёр «Числа»**: формат «словами → цифрами» (на карточке число по-французски, ответ —
  цифрами); диапазоны те же, расписание и ошибки — отдельно от основного формата.
- **Правило для агента**: в теории примеры и слова для изучения — каждый отдельным пунктом
  списка (одиночный перенос строки в Markdown склеивал строки). Только для новых уроков.
- На будущее («Веха 4»): разбить «Грамматику» в «Темах»; «Числа» на слух.

## 0.10.0 — 2026-10-07

### 011 — Повторение и лексика урока (правки пользователя 2026-10-07)

Спецификация — `specs/011-practice-and-lesson-vocab/`.

- **«Ошибка в роде»** — четвёртая оценка на карточке «русский → французский» у
  существительных с родом: слово считается вспомненным (как «Помню»), а его вопросы
  в тренажёре «Артикли» идут первыми при следующем запуске (пока на них не ответили).
  «Отменить последнюю оценку» отменяет и это. В итоге сеанса — отдельной строкой.
- **Переводы помещаются на карточке**: несколько переводов — каждый своей строкой, длинный
  текст — меньшим шрифтом, длинное слово переносится (обе стороны, ввод ответа, результат).
- **Повторить ошибки сразу**: на итоге сеанса — «Повторить „Не помню“ (N)» и «Повторить
  „Не помню“ и „С трудом“ (M)». Это тренировка без записи: оценки не меняют расписание
  и историю. «Ошибка в роде» в повтор не входит.
- **Фильтры в «Лексике» урока**: по теме (темы слов этого урока) и по виду (слова / глаголы /
  фразы); стрелки и ← / → на странице слова листают отфильтрованный список, «назад» —
  к лексике с тем же фильтром.
- **Настройка повторения**: в поле «Тема» только темы, у которых есть слова. Из урока
  («Повторить слова урока») — необязательный фильтр «Тема» только с темами этого урока;
  в сеанс — слова выбранной темы из этого урока.
  Фильтры «Лексики» урока («Тема», «Вид» — по отдельности или вместе) переходят в настройку:
  «Повторить слова урока» открывает её с этим уроком и этими фильтрами; без фильтров — только
  с уроком. «Закончить» на итоге такого повторения возвращает в лексику урока с теми же
  фильтрами (из «Практики» — в «Практику»). В режиме «По уроку» фильтры связаны: в «Теме» —
  только темы, где есть слова выбранного вида, в «Виде» — только виды, где есть слова
  выбранной темы; ставший пустым выбор сбрасывается на «все».
- База прогресса — схема v5 (таблица `trainer_priority`), обновляется сама при запуске.

## 0.9.1 — 2026-10-07

### Страница слова в словаре (правки пользователя 2026-10-07)

- Стрелки «‹ ›» листают слова того урока или темы, откуда слово открыто (в уроке — сначала
  новые, затем на повторение, как в списке урока); надпись сверху ведёт назад туда же
  («Урок 14 › Лексика»). Раньше со страницы урока листался весь словарь.
- Карточка слова — как карточка повторения (макет А, `docs/mockups/2026-10-07-vocab-card.html`):
  по центру, полоска рода сверху, род в скобках за словом — «la maison (f)», стрелки по бокам
  самой карточки, «N из M» в углу. Верхняя часть (слово, 🔊, переводы) всегда одного размера —
  «Подробнее» раскрывается под ней, карточка растёт вниз.
- Метка происхождения перевода («материал урока», «создано ИИ» и т. п.) больше не стоит
  рядом с переводом на карточке: при включённом «Происхождении» она в «Подробнее» строкой
  «перевод: …» (конституция, принцип I — происхождение остаётся доступным).
- На компьютере клавиши ← и → листают слова на странице слова (как стрелки у карточки);
  при вводе в поля («Изменить») клавиши работают как обычно.

## 0.9.0 — 2026-10-06

### 010 — Правки после первого использования

Список пользователя от 2026-10-02, спецификация — `specs/010-first-use-fixes/`.

- **Быстрая оценка карточки** (пункт 8): после «Помню / С трудом / Не помню» следующая
  карточка появляется за ≈ 0,2 с вместо ≈ 1,8 с (на 489 словах). Причина была в том, что на
  каждом шаге заново заводились карточки для всех слов словаря, а библиотека расписания
  тратит на каждую ≈ 1,5 мс. Теперь заводятся только недостающие.
- **Обе стороны сразу**: поэтапного режима больше нет — у каждого слова сразу есть карточки
  «французский → русский» и «русский → французский» (у уже добавленных слов вторая карточка
  появится при первом запуске). Блоки «Новые слова» и «Карточек за один подход» убраны
  из «Настроек».
- **Повторение из урока и темы** (пункты 3, 6): «Повторить слова урока» / «Повторить слова
  темы» открывают страницу настройки с уже выбранным уроком или темой — там направление, вид,
  ввод ответа и «Слов за подход» (пусто — все слова одним подходом; по умолчанию для урока
  и темы — все). Внизу формы — сколько карточек будет в сеансе.
- **Перемешивание** (пункт 5): порядок карточек случайный при каждом запуске; в «Пора
  повторить сегодня» сначала слова, у которых подошёл срок, потом новые.
- **Выбор темы с поиском** (пункт 11): поле, в котором список тем сужается по мере ввода
  (без учёта регистра и акцентов: «etre» находит «Глагол être»), выбор стрелками и Enter.
- **Карточка «русский → французский»** (пункт 2): до ответа род не виден ни полоской, ни
  меткой; после переворота — виден.
- **Страница слова** (пункт 1): стрелки «‹ ›» к соседним словам того списка словаря, из
  которого слово открыто (с его фильтрами), и «N из M».
- **Панель французских букв** (пункт 4): появляется прямо под полем, в котором курсор, и
  больше не висит наверху экрана.
- **Теория и текст рядом** (пункт 9): ссылки «Теория к упражнению» и «Текст к упражнению»
  убраны; «Теория рядом» / «Текст рядом» открываются кнопкой (по умолчанию закрыты);
  в панели — «Открыть отдельной страницей».
- **Картинка у всех упражнений** (пункт 10): у любого упражнения из фото есть «Показать
  картинку»; если картинка нужна для решения — открыта сразу, как раньше.
- Стрелки «‹ ›» у слов и упражнений больше не «прыгают» при открытии страницы.
- **«Не согласна с ответом»** (пункт 7): кнопка сразу показывает «Отправляю…», после отправки
  у пункта видно «Сообщение сохранено…» и метку «✉ сообщение отправлено»; пустое сообщение
  не отправляется — подсказка у пункта. Отправка больше не перечитывает всё хранилище.
- **Классная работа** (пункт 12): упражнения «В классе» всегда отмечены «✓ выполнено».
- Запуск приложения (ярлыки и обновление) — через `python -m french_learning.cli serve`:
  политика Windows начала блокировать `french-learning.exe` в папке разработки.

## 0.7.0 — 2026-09-30

### 006 — Чтение с переводом

- Выделение французского текста (слово, фраза, предложение, абзац) — подсказка с переводом,
  начальной формой («achètent» → «acheter — покупать»), 🔊 и «+ В словарь». Работает в текстах
  и теории уроков, упражнениях, «Теории рядом», доп. материалах, словаре, карточках, темах
  и тренажёрах; под переводом — полоска «пометка · вопрос» (005).
- Перевод: словарь пользователя → запас сохранённых переводов (без интернета, мгновенно) →
  сервис MyMemory (без ключа) или DeepL (ключ `DEEPL_API_KEY` в `.env`). Во внешний сервис
  уходит только выделенное; ответы сервиса сохраняются в запас без дублей.
- «+ В словарь» одним нажатием: слово — в начальной форме, несколько слов — фразой;
  перевод с происхождением «внешний сервис», предложение-пример и урок, без темы; род —
  по артиклю перед словом; повторное добавление не создаёт дубль.
- Начальная форма — локально (simplemma), омонимы по слову перед выделенным
  («Paul entre» → entrer, «il commande» → commander).
- Меню «⋯» — переключатель «Перевод при выделении»; «Настройки» — сервис перевода, почта
  для MyMemory, число сохранённых переводов и «Очистить».
- Страница слова: все примеры с «урок N», метки происхождения переводов при
  «Происхождение: везде».
- База прогресса — схема 4 (таблица `translations`), новая зависимость simplemma.
