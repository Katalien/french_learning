# Шаблоны описи и отчёта

## Опись (до обработки — ждать ответа пользователя)

```
Урок {N} · предлагаемая дата: {дата} ({по дате съёмки / по датам файлов}) — верно?
Темы (по материалам): {тема 1}; {тема 2}; …

В классе
 1. {файл} — {классификация}
    → {элемент}: упр. {номер} «{тема} — {описание}» ({тип}){, справка: …}
 2. …
Домашка
 k. {файл} — {классификация} → …
Не обрабатываются: {медиа / дубли / неподдерживаемые — с причиной}

Вопросы:
 • {крупное сомнение с вариантами}

Какие задания добавить? По умолчанию — все как основные.
Если укажете выбор, неупомянутые попадут в «Резерв».
```

При повторном запуске добавить блок:

```
Уже обработано: {n} файлов (не читаю повторно)
Новые файлы: …
Изменённые файлы (решите по каждому: обновить / добавить как новое / пропустить):
 • {файл} — что изменилось: {кратко}
Исчезли с диска: {файлы из журнала} (контент не трогаю)
```

## Отчёт (после сохранения)

```
Урок {N} {добавлен | дополнен} · коммит «{сообщение}» · {копия отправлена ✅ | ⚠ {предупреждение}}
Файлы: {обработано} обработано, {дубли} дублей, {медиа} медиа (записаны), {не распознано} не распознано
Добавлено: теория {x} · тексты {x} · упражнения {x} (осн. {x}, необяз. {x}, резерв {x}) · слова {x} (новых {x})
Требует проверки ({n}):
 • {где} — {что под сомнением}
Новые темы: {… | нет}
Новые типы упражнений: {… | нет}
Пропущено: {файл — причина | нет}
Проверить в приложении: http://127.0.0.1:8000/lessons/{N}
```

Если сохранение не удалось — что именно не прошло проверку и что сделано
(черновик сохранён в `.staging/{op}/`, можно повторить).
