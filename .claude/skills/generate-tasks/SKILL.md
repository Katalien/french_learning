# /generate-tasks — задания для тренажёра

Ввод пользователя: `$ARGUMENTS`

Отвечай по-русски. Формат пакета — `docs/content-format.md`, раздел «Дополнения функции 004».
Делай **только** это (конституция X): генерация — только по явной просьбе, ровно столько
заданий, сколько попросили (по умолчанию 20; «3 порции» = 3 × размер порции, 60).
Операция `<op>` = `tasks-ГГГГММДД-ЧЧММ`.

1. `uv run french-learning trainer-context <id>`. Нет тренажёра (код 2) — задания
   **не создавай**, предложи сначала добавить его: `/add-trainer <описание>`.
   Если id неясен — `uv run french-learning trainers-list` и уточни у пользователя.
2. Составь задания строго по `trainer.rules` и типу `trainer.exercise_type`:
   - лексика — **в основном из `vocabulary`**, грамматика — из тем и теории пройденных
     уроков (`lessons`);
   - новых слов (нет в `vocabulary`) — **не больше 2 на задание**, каждое — в `new_words`
     с переводом (`{text: "le beurre", translation: "масло"}`);
   - в `answers` — **все** допустимые варианты (разный порядок слов, обе формы, если обе
     верны); французский — строго по конституции VIII (буквы, диакритика, дефисы);
   - не повторяй задания из `existing_tasks`;
   - сомнение в правильности ответа → `needs_review: {flag: true, note: "…"}`;
   - инструкция `instruction_ru` — по-русски, коротко; сами задания — по-французски.
3. Пакет: `uv run french-learning new-ids tb` → файл
   `.staging/<op>/trainers/<id>/tb-xxxxxxxx.yaml` с полями `id`, `kind: task_batch`,
   `trainer`, `type` (= `exercise_type`), `created` (сейчас), `origin: ai`, `instruction_ru`,
   `options` (для `gap_choice`), `items` с номерами 1…N. Большую просьбу («3 порции»)
   можно разбить на несколько пакетов.
4. `uv run french-learning stage-check --op <op>` → исправь ошибки →
   `uv run french-learning commit-staging --op <op> -m "Тренажёр <id>: N заданий"`.
5. Отчёт: сколько заданий создано, сколько с пометкой «требует проверки» (и почему), какие
   новые слова использованы, результат отправки; ссылка
   `http://127.0.0.1:8000/trainers/<id>`.
