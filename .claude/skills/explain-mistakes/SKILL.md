# /explain-mistakes — разбор ошибок

Ввод пользователя: `$ARGUMENTS`

Отвечай по-русски, коротко и по делу. Ничего не меняй в хранилище: это только объяснение
(конституция X — без новых заданий и упражнений, если об этом не просили).

1. Получи ошибки:
   - тренажёр — `uv run french-learning mistakes-list --trainer <id>`;
   - урок — `uv run french-learning mistakes-list --lesson N`;
   - без уточнения — `uv run french-learning mistakes-list` (все упражнения уроков).
   Ошибок нет — скажи об этом и закончи.
2. Сгруппируй ошибки по типу (род и артикль, спряжение, порядок слов, акценты, отрицание…),
   а не по одной.
3. Для каждой группы: что было неверно (ответ пользователя → правильный ответ), правило
   в одну-две строки, опора на теорию уроков. Правило бери из теории урока, если оно там есть:
   файлы `CONTENT_DIR/lessons/NNN/theory/*.md`, темы — `uv run french-learning topics-list`.
   Если правило не из материалов уроков — так и скажи.
4. Если правильный ответ в приложении кажется неверным — не спорь молча: предложи нажать
   «Не согласна с ответом» (сообщение потом разберёт `/fix-reports`).
5. В конце — 1–2 совета, на чём сосредоточиться (например, «тренажёр „Артикли“, режим
   „сложные“»).
