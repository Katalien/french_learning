# /fix-reports — разбор сообщений об ошибках

Ввод пользователя: `$ARGUMENTS`

Прочитай `.claude/skills/_shared/content-rules.md`. Отвечай по-русски.
Операция `<op>` = `fix-ГГГГММДД-ЧЧММ`.

1. `reports-list` (открытые). Пусто → «Неразобранных сообщений нет» и закончить.
2. По каждому сообщению: открой файл элемента (`element_path`) и исходник (`sources`,
   сжатая копия в хранилище); если нужно — оригинал в `SOURCE_MATERIALS_DIR`. Сверь
   и реши, права ли жалоба.
3. **Права** → исправь элемент: копия его файла с правкой в `.staging/<op>/<element_path>`
   (id и остальные поля не меняй; снятое сомнение — убрать `needs_review`). Все исправления
   одним черновиком → `stage-check`, `commit-staging --op <op> -m "Исправления по сообщениям"`.
   Затем для каждого: `report-resolve <id> fixed --resolution "<что исправлено>"`.
4. **Не права** → `report-resolve <id> rejected --resolution "<почему верно, по какому
   правилу>"` — коротко и понятно, с примером.
5. Не уверен → не закрывай; в сводке спроси пользователя.
6. **Сводка**: сколько исправлено / отклонено / оставлено, по каждому — одна строка
   с пояснением. Напомни: история выполнения упражнений сохраняется, результаты
   пересчитаются после функции 004.
