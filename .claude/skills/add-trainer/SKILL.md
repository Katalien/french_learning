# /add-trainer — новый тренажёр

Ввод пользователя: `$ARGUMENTS`

Отвечай по-русски. Формат каталога — `docs/content-format.md`, раздел «Дополнения функции
004». Код приложения **не меняй**. Операция `<op>` = `trainer-ГГГГММДД-ЧЧММ`.

1. `uv run french-learning trainers-list` — нет ли похожего тренажёра. Есть — предложи
   его вместо нового.
2. Подбери тип заданий из поддерживаемых:
   `gap_input` (пропуск, ввод), `gap_choice` (пропуск, выбор из вариантов), `multi_gap`
   (несколько пропусков), `transform` (преобразовать предложение), `choice` (выбор
   ответа), `two_forms` (одна из двух форм), `true_false` (верно / неверно).
   Идея не укладывается ни в один (нужны аудио, картинка, сопоставление, свободный ответ
   с проверкой по смыслу…) — **не добавляй** тренажёр: объясни, что нужна доработка
   приложения (новый тип упражнения), и предложи записать идею в `docs/roadmap.md`.
3. Запись в `trainers.yaml` (весь файл копией в `.staging/<op>/trainers.yaml`; файла нет —
   создай с ключом `trainers:`):
   - `id` — короткий латиницей через дефис (`est-ce-que`), не из встроенных;
   - `name`, `description` — по-русски; `source: agent`; `exercise_type`; `origin: ai`;
   - `rules` — правила генерации для `/generate-tasks`: что спрашивать, какая грамматика,
     какие ограничения, пример 1–2 заданий с ответами.
   Переключить встроенный тренажёр на задания от агента: запись
   `{id: <встроенный>, source: agent, rules: "…"}` (менять можно только `source`,
   `exercise_type`, `rules`).
4. `uv run french-learning stage-check --op <op>` →
   `uv run french-learning commit-staging --op <op> -m "Новый тренажёр: <название>"`.
5. Отчёт: что добавлено, тип заданий, правила; предложи сгенерировать первую порцию:
   `/generate-tasks <id>`.
